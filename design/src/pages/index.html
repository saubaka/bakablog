请你看什么

按这张清单看，一遍就够。

  • 颜色和线条：是不是足够浅、足够干净？有没有哪里让你觉得“灰”“重”？线条和统计卡片那种浅蓝是不是一致？
  • 可爱程度：涂鸦、胶带、邮戳、便利贴，是太多、刚好，还是不够？
  • 滚动动效：慢慢滚、快速甩、倒着滚。标题逐字上浮、卡片上浮、气泡侧滑，节奏舒服吗？右下角「设计面板」可以切换「标准 / 轻柔 / 关闭」。
  • 手机宽度：把窗口缩到最窄，或者用手机访问。底部胶囊导航、目录抽屉、卡片排列。
  • 文章页顶部的细线：读文章时屏幕最上方有一条 2px 的浅粉阅读进度线。如果你不喜欢屏幕上方有任何线，我就去掉它。
  • 字体：中文用系统圆体，英文用丸ゴ。在 Safari 里看是不是你想要的圆润感？

说明

这些页面是怎么来的

纯 HTML / CSS / JS，没有安装任何依赖。样式分在同一套有序的层里，滚动动效是一个独立的小引擎。通过之后，这些样式和引擎会原样搬进 Vue 项目里。
