# sau_bakaの博客（baka blog）

一个浅蓝浅粉浅色系的可爱风个人网站，使用 Python、Flask 和 SQLite 构建。这里可以发布博客手记、展示项目作品、记录生活动态、整理相册，也提供友链、留言簿和覆盖全站内容的搜索，并配有功能完整的单人管理后台。

所有样式、脚本、图标、字体、依赖包和数据都随项目本地提供，不依赖 CDN 或任何强制云服务。

## 主要功能

- **博客**：可视化文章编辑器、草稿与定时发布、置顶推荐、版本恢复、分类与标签、月度归档、Atom 订阅与站点地图。
- **个人内容**：个人资料与技能、项目作品展示、生活动态、相册瀑布流与灯箱。
- **互动**：友链申请与审核、文章评论、留言簿；公开互动带限流、蜜罐和敏感词防护。
- **全站搜索**：独立的 `/search/` 页面，统一检索文章、项目、动态、友链和留言，支持严格与自由两种匹配方式，自动防抖与分页。
- **管理后台**：单管理员模式，包含仪表盘、内容管理、站点设置、主题外观（字体、页面动画、弹窗样式）、操作日志、备份与恢复。
- **统一登录（可选）**：可作为 OIDC 客户端接入相邻的云门（Cloudgate）网关，实现前台访客登录与管理员统一认证；不接入时仅使用本地管理员账号。

## 快速开始（Windows）

需要 Python 3.11–3.14。直接双击项目根目录的 `start.bat`：

- 只使用 Windows CMD 和本地 Python，不修改执行策略、不提权、不联网下载；
- 首次运行会自动创建虚拟环境，并从本地 `wheelhouse/` 离线安装全部依赖；
- 每次启动前自动执行数据库迁移和系统检查，然后以 `http://127.0.0.1:5000/` 提供服务。

首次使用需要创建管理员账号：

```powershell
.\.venv\Scripts\python.exe -m flask --app wsgi:app site-init
```

按提示输入管理员用户名和至少 14 位的密码，然后用它登录 `http://127.0.0.1:5000/admin/login/`。

只想检查环境而不启动服务时，可运行 `start.bat --check-only`；监听地址和端口可通过 `CLOUD_DIARY_HOST`、`CLOUD_DIARY_PORT` 环境变量调整，更多环境配置见 `.env.example`。

## 技术说明

- 服务端：Flask 应用工厂 + Blueprint 模块化结构，Jinja2 服务端渲染。
- 数据库：本地 SQLite（WAL、外键、繁忙超时），结构迁移由 Alembic/Flask-Migrate 管理。
- 前端：本地 CSS 与原生 JavaScript 渐进增强，内置细腻的物理动效，并完整支持“减少动态效果”和低性能设备降级。
- 安全：CSRF、登录限流、安全响应头、请求指纹（不记录原始 IP）、数据库与媒体联合备份及恢复前安全副本。

## 部署

Windows 环境用于本地运行与测试；正式部署可使用 Debian 12 或其他受支持的 systemd Linux。`deploy-linux.sh`默认从`https://github.com/saubaka/bakagateway.git`克隆或更新项目并安装`bakagate`。管理器负责systemd持久服务、开机自启、日志轮转、唯一域名、Cloudflare Origin CA证书以及`127.0.0.1`动态端口；端口冲突时会自动切换并同步Nginx。完整步骤见`DEPLOY-DEBIAN12.md`。

## 目录结构

| 路径 | 内容 |
| --- | --- |
| `app/` | Flask 应用：前台/后台蓝图、模板、静态资源与服务层 |
| `migrations/` | 数据库迁移 |
| `scripts/` | 初始化、开发、备份、恢复与生产预检脚本 |
| `wheelhouse/` | 离线安装用的本地 wheel 依赖 |
| `tests/` | 自动化测试（`pytest`） |
| `docs/` | 规划与设计记录 |
| `instance/` | 运行数据：数据库、上传、备份与日志（运行时生成） |
