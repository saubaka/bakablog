# 阶段一交付物索引

阶段一目标是把需求和技术方案固化为可以直接指导后续设计、开发、测试与部署的文档。本阶段不编写业务代码。

## 已确认基线

- Python + Flask 模块化单体应用。
- Jinja2 服务端渲染，原生 CSS 与 JavaScript 渐进增强。
- SQLite 本地数据库，使用 SQLAlchemy 和 Alembic/Flask-Migrate。
- 上传、媒体、日志、备份、字体、图标和前端依赖全部本地保存。
- 不使用 CDN、云对象存储、Redis、外部数据库或必须联网的运行时服务。
- Windows 可使用 Waitress，Linux 可使用 Gunicorn；生产环境不使用 Flask 开发服务器。
- 定位为单机、读多写少的高性能个人网站。

## 默认假设

在用户未另行指定前，后续阶段按以下假设执行：

- 网站为单站点、单站长模式，界面默认使用简体中文。
- 公开访客不注册账号；管理员、编辑和作者账号由管理员在后台创建。
- 评论、留言和友链申请允许匿名提交，但首次或可疑内容需审核。
- 首发版本不包含私密文章、付费内容、实时聊天和第三方 OAuth 登录。
- 开发环境为当前 Windows 工作区；部署同时保留 Windows 与 Linux 单机方案。
- 生产数据目录与源码目录分离，真实数据库、密钥、上传内容和备份不进入版本控制。

这些假设属于可配置决策，不影响第二阶段开始；若后续修改，必须同步更新需求和架构决策记录。
