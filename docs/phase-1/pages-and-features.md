# 页面与前后台功能矩阵

## 1. 公开页面结构

| 前台页面 | 路由建议 | 主要内容 | 后台对应模块 |
| --- | --- | --- | --- |
| 首页 | `/` | 个人卡、精选文章、项目、动态、相册、友链等模块 | 外观 → 首页模块 |
| 博客列表 | `/blog/` | 文章卡片、分页、筛选和排序 | 内容 → 文章 |
| 文章详情 | `/blog/<slug>/` | 正文、目录、标签、版权、相关文章与评论 | 内容 → 文章编辑 |
| 分类 | `/blog/category/<slug>/` | 分类介绍与文章列表 | 内容 → 分类 |
| 标签 | `/blog/tag/<slug>/` | 标签文章列表 | 内容 → 标签 |
| 归档 | `/blog/archive/` | 年月时间线 | 由文章发布时间生成 |
| 搜索 | `/search/` | 文章、项目、动态和页面结果 | 系统 → 搜索状态 |
| 关于我 | `/about/` | 介绍、技能、经历、目标与联系入口 | 个人 → 个人资料/经历 |
| 项目列表 | `/projects/` | 项目卡片与筛选 | 个人 → 项目 |
| 项目详情 | `/projects/<slug>/` | 项目说明、截图和链接 | 个人 → 项目编辑 |
| 动态列表 | `/moments/` | 短内容时间线 | 内容 → 动态 |
| 动态详情 | `/moments/<id>/` | 动态、图片与互动 | 内容 → 动态编辑 |
| 相册列表 | `/gallery/` | 相册封面与分类 | 媒体 → 相册 |
| 相册详情 | `/gallery/<slug>/` | 照片流和灯箱 | 媒体 → 相册编辑 |
| 友链 | `/links/` | 友链卡片、分类和申请入口 | 互动 → 友链/申请 |
| 留言板 | `/guestbook/` | 留言、回复和提交表单 | 互动 → 留言 |
| 独立页面 | `/pages/<slug>/` | 自定义正文 | 内容 → 独立页面 |
| RSS | `/feed.xml` | 已发布文章订阅 | 系统 → SEO/订阅 |
| 站点地图 | `/sitemap.xml` | 可索引公开URL | 系统 → SEO |
| 404/错误页 | 系统路由 | 可爱错误提示和返回入口 | 外观 → 错误页面设置 |

## 2. 后台信息架构

### 2.1 仪表盘

- 内容数量、草稿、待发布和最近更新。
- 待审核评论、留言和友链申请。
- 最近登录与关键操作摘要。
- SQLite文件大小、WAL状态、最近备份和媒体空间。
- 快速创建文章、动态、项目和相册。

### 2.2 内容

- 文章：列表、筛选、新建、编辑、预览、发布、归档、回收站和版本。
- 分类与标签：创建、编辑、排序、合并与引用计数。
- 动态：文字、图片、心情、可见状态和发布时间。
- 独立页面：正文、永久链接、导航关联和SEO。

### 2.3 个人

- 个人资料：昵称、头像、签名、简介、位置和公开联系方式。
- 经历：时间、标题、机构、描述、图标和排序。
- 技能：名称、分组、熟练度展示方式和排序。
- 项目：封面、技术、状态、截图、链接、正文和推荐。

### 2.4 媒体

- 媒体库：上传、搜索、筛选、替代文字、引用和删除。
- 相册：封面、描述、照片、排序、可见状态和EXIF开关。
- 存储检查：孤立文件、缺失文件、重复文件和空间统计。

### 2.5 互动

- 评论：待审核、已公开、垃圾、举报、回复和批量操作。
- 留言：审核、回复、置顶、屏蔽和联系方式保护。
- 友链：分类、排序、状态、可用性检查和下线。
- 友链申请：查看、审核、拒绝、转为友链和备注。

### 2.6 外观

- 首页模块：开关、顺序、标题、数量、样式和设备可见性。
- 导航：层级、文字、图标、URL、打开方式、权限和排序。
- 页脚：版权、备案、社交入口和自定义文字。
- 主题：颜色、字体、圆角、阴影、布局宽度和动效等级。

### 2.7 系统

- 站点设置：名称、描述、时区、语言和基础SEO。
- 用户与角色：管理员创建账号、停用和分配角色。
- 搜索：FTS5状态、重建索引和降级状态。
- 备份：创建、列表、校验和恢复说明。
- 日志：登录、操作和错误摘要。
- 系统状态：版本、数据库、媒体、缓存和运行环境。

## 3. 关键页面状态

每个列表和详情页都必须设计以下状态：

- 正常且有内容。
- 首次使用或无内容。
- 筛选、搜索无结果。
- 加载中或提交中。
- 输入校验失败。
- 服务端处理失败。
- 无权限或登录过期。
- 内容已删除、未发布或永久链接不存在。

空状态必须给出合理下一步，不使用只有装饰图片而没有说明的空页面。

## 4. 前后台一致性规则

- 前台出现的标题、封面、描述、标签、顺序、可见状态都必须有后台编辑入口或明确的自动生成规则。
- 后台字段名称应与前台概念一致，避免同一概念使用不同名称。
- 后台修改公开内容后，相关缓存和搜索数据必须同步失效或更新。
- 后台预览使用与前台相同模板和本地资源，但预览URL不可被搜索引擎索引。
- 前台不显示后台备注、联系方式、IP、审核原因和内部状态。

## 5. 菜单跳转规划

### 桌面端主菜单

- 首页
- 博客
- 项目
- 动态
- 相册
- 友链
- 关于
- 更多：归档、留言、搜索和独立页面

### 移动端底部菜单

- 首页
- 博客
- 动态
- 友链
- 更多

“更多”打开本地渲染的圆角抽屉，包含项目、相册、关于、归档、留言和搜索。菜单必须支持当前项标识、键盘焦点、返回键关闭和减少动画模式。

## 6. SEO与公开状态

- 只有已发布且允许索引的内容进入站点地图和搜索。
- 草稿、预览、后台、审核和回收站页面统一禁止索引。
- 文章、项目、相册和独立页面支持自定义标题、描述和本地分享图。
- 分类、标签和分页页使用规范链接，避免重复内容。
- 永久删除或改址时使用明确404/410或本地重定向记录。
