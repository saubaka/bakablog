# 阶段六：个人内容与首页配置

阶段六已经完成个人内容、项目作品、生活动态和可配置站点内容的前后台闭环，应用版本为`0.6.0`。

## 交付物

- [开发与管理员使用说明](development.md)
- [数据模型与公开规则](content-model.md)
- [验收记录](validation.md)

## 已完成能力

- 后台维护显示名称、身份简介、地点、邮箱、头像、详细介绍和简历地址。
- 技能、经历、目标和社交链接可新增、编辑、排序、隐藏和删除。
- 项目作品支持Markdown详情、技术栈、封面、外链、精选、排序、草稿、发布与回收站。
- 生活动态支持Markdown、心情、地点、置顶、草稿、发布和删除。
- 首页欢迎区、文章、项目、动态和关于模块支持开关、排序、数量与样式参数。
- 自定义导航、页脚文字和独立页面均可从后台维护。
- 项目、动态和独立页面自动进入站点地图，公开状态统一隔离。
