# 阶段六开发与管理员使用说明

## 升级

```powershell
.\scripts\bootstrap.ps1 -Offline
.\.venv\Scripts\python.exe -m flask --app wsgi:app db upgrade
```

迁移会创建个人内容、项目、动态、首页配置、导航和独立页面表，并写入五个默认首页模块。迁移不会修改或重建Stage 5的FTS5全文索引。

## 管理入口

| 入口 | 用途 |
| --- | --- |
| `/admin/profile/` | 个人档案、技能、经历、目标和社交链接 |
| `/admin/projects/` | 项目作品、封面、外链和发布状态 |
| `/admin/moments/` | 生活动态、心情、地点和置顶 |
| `/admin/site-content/` | 首页文字、模块开关/顺序/数量/样式、导航与页脚 |
| `/admin/pages/` | 自定义独立页面和导航展示 |

## 内容维护建议

- 首页模块排序数字越小越靠前，数量限定为1至12。
- 项目和动态保存为草稿时不会通过任何公开入口访问；发布后才进入列表和站点地图。
- 项目封面从本地媒体库选择，图片仍由既有Pillow安全处理流程生成。
- 社交、导航、项目和简历链接仅允许站内绝对路径以及`http`、`https`、`mailto`协议。
- 自定义页面使用与博客一致的Markdown白名单净化流程。
