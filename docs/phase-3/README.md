# 阶段三交付物：项目骨架与通用组件

阶段三已经把视觉原型转换为可直接运行的 Flask 应用。当前版本提供前台与后台共用的设计系统、响应式页面骨架、本地静态资源、通用 UI 组件、开发与生产启动脚本，以及自动化测试基础。

## 交付内容

- Flask 应用工厂、开发/测试/生产配置和 Blueprint 模块结构。
- 前台、后台、404 与 500 错误页面的 Jinja2 布局。
- 首页、博客列表、文章详情、关于、友链、组件展示、空状态和后台仪表盘占位页面。
- 按钮、卡片、徽章、表单、消息、骨架屏、弹窗、抽屉和 Toast 等通用组件。
- 桌面悬浮导航、移动底部导航、前台移动抽屉和后台响应式侧栏。
- 浅蓝、浅粉、浅灰、白色主题，以及圆角、阴影、弹性反馈和减少动态效果支持。
- 全本地 CSS、JavaScript 与 SVG 图标精灵，不加载 CDN 或远程字体。
- 依赖锁定、Windows 离线 wheelhouse、开发/生产/测试 PowerShell 脚本。
- 路由、配置、安全响应头、本地资源和模板引用自动化测试。
