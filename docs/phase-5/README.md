# 阶段五：博客核心功能

阶段五已经完成从后台写作到前台阅读的完整博客闭环，应用版本为`0.5.0`。

## 交付物

- [开发与使用说明](development.md)
- [内容模型与发布规则](content-model.md)
- [验收记录](validation.md)

## 已完成能力

- 文章、分类、标签、多版本快照与软删除。
- 草稿、立即发布、定时发布、置顶、推荐、预览、撤回和自动保存。
- 本地Markdown渲染、HTML白名单净化、代码高亮、提示块和编辑器图片上传。
- 前台分页、分类标签筛选、搜索、月度归档、目录、灯箱、阅读进度和相关推荐。
- SQLite FTS5全文索引与无FTS5时的LIKE降级查询。
- canonical、文章描述、Open Graph基础标签、Atom订阅和XML站点地图。

阶段六不在本阶段范围内：个人资料、项目、动态、相册、友链申请和首页模块配置仍按原计划后续实现。
