# 内容模型与发布规则

## 核心数据

| 模型 | 作用 | 关键约束 |
| --- | --- | --- |
| `Post` | 文章正文、状态、SEO和发布时间 | slug唯一；状态仅草稿、已发布、定时发布 |
| `PostVersion` | 手动保存与恢复的正文快照 | 每篇文章版本号唯一且递增 |
| `Category` | 单一文章分类 | 名称、slug唯一 |
| `Tag` | 多对多文章标签 | 名称、slug唯一 |
| `post_tags` | 文章标签关联 | 文章和标签组合唯一 |

## 公开规则

文章只有同时满足以下条件才会出现在任何公开查询中：

- 未进入回收站；
- 状态为`published`或`scheduled`；
- `published_at`存在且不晚于当前UTC时间。

同一规则复用于首页、列表、详情、分类标签、归档、相关文章、Atom和站点地图，避免不同入口泄露草稿或未来内容。

## 版本与删除

- 自动保存只更新当前草稿，不制造大量版本。
- 每次手动保存、撤回或恢复旧版会创建新快照。
- 恢复旧版始终生成新草稿，不直接覆盖线上发布状态。
- 删除为软删除；恢复后保留正文、关系和版本历史。
