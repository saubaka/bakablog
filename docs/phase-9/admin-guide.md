# 管理员使用说明

## 首次创建与安全重置

当数据库中没有活动超级管理员时，访问`/bakaadmin`会自动显示“创建唯一管理员”。本机开发环境可直接填写；远程或生产环境先在服务器执行`flask issue-admin-setup-code`，并在30分钟内使用输出的一次性口令。

需要废弃旧管理员凭据时，先停止应用写入，再执行`flask reset-superadmin --yes`。命令会先创建并验证完整站点备份，再撤销旧密码、角色和全部会话，并保留承接文章、媒体外键的不可登录槽位。完成后重新访问`/bakaadmin`创建新管理员；旧凭据不会恢复。

## 超级管理员登录

后台入口为`/bakaadmin`。管理员用户名只允许规范化后的安全字符，密码至少14字符且不能包含用户名或使用常见弱密码。15分钟内连续5次失败会暂时限制该用户名与请求指纹。退出后会话被清除。

首个超级管理员通过`flask create-superadmin`交互创建；前台不提供账号创建或用户模块。登录只使用`/bakaadmin`，每次都需要完成本地图片人机验证。

## 前后台对应关系

- 首页、导航、页脚、独立页：站点配置。
- 博客、分类、标签、版本：文章管理。
- 关于、技能、经历、目标、社交：个人资料。
- 项目与动态：各自管理页面。
- 友链：申请审核、分类、排序、停用与可用性检查。
- 相册：相册发布、照片批量上传、说明与排序。
- 评论和留言：统一审核中心、回复、置顶与屏蔽。
- 本地图片：媒体库；被业务内容引用的媒体不能直接删除。
- 运行摘要：系统状态，展示版本、迁移、SQLite、磁盘用量、日志和最近备份状态。

## 发布流程

草稿不公开；文章、项目、动态和相册必须显式发布。定时文章只有达到发布时间才公开。删除文章和个人内容优先进入回收站，确认无引用后再永久处理。上传图片前在本地缩放到合理尺寸，避免用16MiB上限当作日常目标。

评论、留言和友链申请默认按审核状态公开。不要把审核后台显示的用户代理、请求指纹或申请信息复制到公开页面。

## 管理习惯

1. 发布前使用预览并检查手机排版、替代文字、链接协议和图片来源。
2. 修改导航、域名或SEO文本后检查canonical、robots、Atom和sitemap。
3. 批量操作前创建并验证联合备份。
4. 看到系统状态“就绪失败”、迁移不一致或SQLite非`ok`时停止写操作并联系维护者。
5. 不在浏览器、截图、工单或会话记录中保存生产密码、密钥和Cookie。
