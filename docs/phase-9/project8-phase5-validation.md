# 项目8移植第五阶段：后台设置、预览与长尾覆盖

日期：2026-10-09。应用版本：Cloudtrace 1.41.0。

## 实施范围

只改当前项目1及其内部bakagit；源项目8只读，多用户版不改。首选端口5010、正式数据库与管理员状态不变。第六阶段（全量验收）没有提前实施。

## 已完成

- **通知动效分类型设置**：后台“主题 → 弹窗与通知”新增“通知动效”卡片。成功、信息、提醒、错误、处理中五种类型各自设置进入（默认780ms，0–3000）、退出（680ms，0–3000）、文字退出（160ms，0–1000）、文字进入（340ms，0–1000），另有一个全局“堆叠过渡”（320ms，0–1500）。提供快速、标准、舒缓三个预设，点击预设会改写全部输入框；数值和预设一致时对应预设会高亮。手机上每种类型显示为一张两列的小卡片。
- **保存与存储**：五种类型和堆叠时长保存为同一个JSON设置（`notification_motion`），一次保存是单行写入。页面通过`<html data-notice-motion>`在首屏就带上配置，通知运行时按类型读取，缺失或越界的字段逐项退回默认值。读取时从不写回数据库：若存储的JSON损坏，页面使用默认值，数据库里的原内容保持不变。
- **版本号防冲突**：整张“弹窗与通知”表单带一个隐藏的`revision`。保存时服务端比较表单版本与当前版本，不一致时返回409，并保留你在页面上填写的草稿，提示“这些设置刚刚在别处更新过，请核对后再保存一次”，同时把表单版本更新为当前值，下一次保存即可成功。成功保存后版本加1，并写入审计记录。校验失败（数值越界或不是整数）时返回400，逐项说明范围，输入框保留你填写的数值（包括越界的），不会清空。
- **草稿预览**：预览按钮使用页面上尚未保存的数值，覆盖成功、信息、提醒、错误、长文、带操作、多条堆叠、处理中转成功、处理中转失败和关闭全部。预览通知用`AbortSignal`与页面绑定：离开该页面时全部预览立刻收起，延时任务（例如处理中转结果的计时）被取消，不会在其他页面突然弹出。预览不会影响正式配置：关闭预览后站点通知仍用已保存的数值。
- **已有设置的含义保持不变**：“停留时间”仍是成功与信息通知的基础阅读时间，不被当作入场时间；通知配色、圆角沿用原来的字段。通知圆角默认值已是28px。
- **弹窗设置现在真实生效**：弹窗轮廓色会混入边框颜色；圆角、宽度、背景模糊、阴影四档（无、轻柔、标准、深层）都直接作用于真实弹窗（用CSS变量和`data-dialog-shadow`）。弹窗默认圆角由30px改为22px，与规划一致；已保存过的值不会被改写。
- **退役无法生效的旧设置**：弹窗预设（柔和、轻透玻璃、纸张、紧凑、云朵、轻线）和弹窗起止渐变色，在第三阶段统一为白底后已经不起作用，本轮从后台表单、保存路由、页面上下文、组件预览页、脚本和样式中全部删除，约30条旧样式规则一并清除。数据库里旧的`dialog_style`、`dialog_color_*`记录保留在表中，运行时不再读取。
- **全站统一滑块**：新增一套本地主题滑块样式，覆盖弹窗设置、动画设置、编辑器图片宽度、图片裁剪框缩放和组件预览，去掉原生外观和各处不同的渐变轨道。裁剪框里的缩放滑块是第四阶段留下的遗留项，本轮已处理。
- **其他长尾**：后台“站点 → 标题与Logo”页面的“IMAGE STUDIO”装饰眉题已删除；弹窗预览区只保留三种系统弹窗，通知预览集中到新的通知动效卡片里。

## 验收与发布边界

项目要求的verify-web-visuals Skill在当前环境里不存在，本轮改用Playwright专项脚本和完整探针完成同等检查。应用内浏览器窗格处于隐藏状态时会暂停动画，因此交互验收都在可见的Playwright Chromium中完成。

验收使用的5019（带测试数据）、5029（空站点向导）两个实例都在会话临时目录，随机密码不落盘到仓库；没有修改正式数据库、没有推送或发布。浏览器原生的`step=10`校验会拦截不是10倍数的毫秒值（例如1234），这是有意保留的输入约束；服务端接受任意范围内整数。

仍属已知范围外的内容：
- 文章和独立页面编辑器仍走原生跳转，规划里的独立浮动子菜单没有改动（第四阶段已说明）。
- 组件预览页中少量早期卡片的装饰性文案和样式由第六阶段的全量走查处理。
- 并发保存的保护只覆盖“弹窗与通知”这一张表单；其他设置页沿用原来的最后写入为准。
