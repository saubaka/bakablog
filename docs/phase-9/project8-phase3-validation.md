# 项目8移植第三阶段：顶部通知与弹窗替换

日期：2026-10-09。应用版本：Cloudtrace 1.39.0。

## 实施范围

只改当前项目1及其内部bakagit；源项目8只读，多用户版不改。首选端口5010、正式数据库与管理员状态不变。增强导航与整页刷新连续性属于第四阶段，通知分类型时长、预设和revision保存属于第五阶段，本轮都没有提前实施。

## 已完成

- **顶部水滴胶囊通知**：新增`app/static/scripts/notifications.js`和`app/static/styles/notifications.css`，旧的右下角`.toast-region`、`.toast`规则、环绕线条和`data-dismiss-toast`全部退役，全站只剩一种通知。通知固定在顶部中央，距顶至少16px并计入安全区；宽度按内容估算在250–340px，始终不超过视口减32px。外观为白底、1px浅蓝实线、28px圆角、小阴影，文字13px、7px状态点、32px圆形关闭按钮。胶囊边框是稳定的CSS实线，不用测量SVG描边。
- **进退场时序**：入场780ms，水滴从上方约70px落下，经圆形缓冲后展开为胶囊，文字在80%处才出现。退场680ms，文字先淡出，胶囊收成圆形，再变回水滴向下落走。展开时文字层宽度固定，不会在胶囊变宽的过程中反复换行；支持`interpolate-size`的浏览器会平滑过渡到自适应高度。
- **处理中→结果**：`CloudtraceNotifications.progress()`在同一个胶囊里先显示处理中，可多次更新，最后一次性转为成功或失败。换字时文字退出160ms、进入340ms，带最多6px的短暂模糊，不会再落下第二颗水滴。如果用户在任务完成前关掉了处理中提示，结果会在它完全退场后单独显示一次。
- **堆叠与交互**：最新的通知在最前面，最多显示前景加三层背景，每层下移9px、缩小0.015。背景层仍是白底，内容隐藏且不可交互。整组通知统一用当前最宽一条的宽度，切换时不会左右跳动。点击胶囊空白处或按Enter/Space轮换到下一条；关闭按钮只关闭这一条；焦点在通知上时按Esc只关闭当前通知，不会顺带关掉下面的弹窗。同时最多保留8条，超出时先移除已结束的普通通知。相同文字、相同类型的通知会合并：已有那条提到最前并重新计时。
- **停留时间**：动画时间和阅读时间分开计算。成功和信息类以后台已有的“停留时间”为基础（默认值从4600ms调到5200ms，数据库里没有存过这个值），每多一个字增加约65ms，上限14秒；提醒类再乘1.35；错误类和处理中一直保留，直到用户关闭或任务完成；任务完成后的结果停留3.2秒。鼠标悬停、焦点进入、处于背景层、标签页隐藏或窗口失焦时都会暂停计时，恢复后从剩余时间接着算，不会重新补满。
- **弹窗里的通知**：通知宿主使用`popover="manual"`进入浏览器顶层。打开模态弹窗时，宿主会移进当前最上层的弹窗里，因此通知显示在弹窗之上，可以点击，也不会破坏弹窗的inert边界；弹窗开始关闭时宿主立刻回到`body`。
- **安全与无障碍**：通知文字只用`textContent`写入，脚本里没有`innerHTML`。错误类使用`role=alert`，其他类型使用`role=status`。通知宿主带`data-no-linkify`，外链脚本不会把通知里的网址改写成链接。服务器的flash消息先渲染成隐藏的纯文本列表，再由脚本转成胶囊；关闭JavaScript时`<noscript>`里会显示一份静态列表。系统减少动态、站点的`data-motion=reduce`以及低性能模式下，所有动画时长变为0，通知直接出现或消失。
- **调用统一**：`CloudDiary.showToast`继续可用，内部改为调用新通知，同时新增`CloudDiary.notify/progress/openDialog/closeDialog`。Flask flash、后台保存、编辑器图片上传（按约34%的步长更新进度，避免每帧都被读屏播报）、正文图片上传、带上传动画的表单（上传失败时提示）和系统更新操作，都改成“处理中→结果”的单个胶囊。项目1本身没有复制到剪贴板的功能，所以没有新增“复制”通知。
- **弹窗统一**：确认框、输入框、提示框、通用弹窗、友链申请、编辑器媒体库和图片裁剪框统一为白底、22px圆角、浅色阴影，边框随弹窗表面一起从`#DCEAF7`过渡到`#BED8EF`，原来额外的环绕线条已删除。进场使用小幅位移、轻微缩放和淡入，背景遮罩同步淡入淡出；退场约240ms，退场期间弹窗仍保持模态且不响应点击。每个弹窗有独立的生命周期：再次打开会取消尚未完成的关闭；连续两次关闭只执行一次；关闭后焦点回到打开它的元素。按Esc也走同样的关闭动画。图片裁剪框改由同一套生命周期打开和关闭，并删除了“IMAGE STUDIO”眉题。后台“弹窗与通知”页面标题改为“弹窗与顶部通知”，预览区可以试成功、长提醒、错误和“处理中转成功”几种通知，组件预览页也加了“处理中”示例。

- 第三阶段专项浏览器脚本在1280×900、768×1024、390×844三种尺寸下均通过，每组6个场景，控制台错误和警告为0，具体是：
