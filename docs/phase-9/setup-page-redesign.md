# 初始化页重构（1.44.0 → 1.48.0）

日期：2026-10-10。应用版本：Cloudtrace 1.48.0。只改项目1及内部bakagit；源项目8只读，多用户版不改；5010、正式数据库不变。

## 经过

1. **1.44.0**：用户指出初始化页的大卡片和按钮边缘仍偏深（动效描边默认色 #BFD9E8 偏明显），并要求重构初始化页。我把描边默认色改为 #D4E6F3，并把页面做成拟态风格（凸起/凹陷的双向阴影、叠放卡片、指针视差）。
2. **1.45.0**：用户反馈拟态的输入框是“凹进去”的，而且AI味很重，要求删除所有输入框等处的拟态效果，改用可爱简洁的样式。这一版把拟态整体去掉。
3. **1.46.0**：用户要求把初始化页里过于“AI腔”的中文描述改朴素；左侧图形占比更大，并删掉左侧卡片的白底和边线；所有文本框加上从页面上方或下方滚动时的入场和出场动画。
4. **1.47.0**：用户要求把左侧“流程图”（三步清单）居中并放大，缩小下方的云朵；删除右侧注册容器卡片的白底和边线；右侧所有文本框和卡片也加上滚动入场出场动画。
5. **1.48.0**：右侧的文本框和文字原来只有滚动时的入场出场，页面刚打开时是直接出现的；用户要求在保留滚动动画的同时，也加上正常的开场入场动画。

## 1.48.0 的改动

- **开场入场**：页面打开时，右侧10个块（标题、分组标题、文本框、密码块、验证码、提交按钮）从上到下依次上浮、去模糊、淡入，每个块比上一个晚约70ms，整体约1.3秒内完成。
- **纯样式实现**：用CSS关键帧动画，不依赖脚本，所以没有脚本时也会播放，也不会出现“先显示再隐藏再入场”的闪动。动画只用`backwards`填充，只在延迟期间保持起始帧，结束后由正常样式和滚动入场出场接手；用`both`或`forwards`会把终点帧钉死，滚动出场就失效了（有测试守着）。
- **两层动画的分工**：开场动画只在页面打开时播一次；之后每次越过上下边缘仍由滚动入场出场负责。减少动态偏好下两者都关闭，所有内容一次显示。

## 1.47.0 的改动

- **左侧居中、流程图放大**：左栏整体居中（标题、说明、清单、小云），并在页面滚动时固定在屏幕中部附近；两栏比例改为1.25:1。三步清单放大：圆点40→56px，步骤名15→20px，说明12→14px，步骤间距加大，连接线加粗。**小云缩小**到约190px。手机和平板上清单仍是横向三点（44px），小云隐藏。
- **右侧不再有卡片**：删掉了表单卡片的白底、边线和阴影，也不再绘制站点的描边动画（该卡片不再是动效表面）；表单直接放在页面底色上。验证码托盘的灰底和边线一并去掉，只保留验证码图片本身的细边。
- **入场出场扩大到右侧所有块**：标题“管理员信息”、三个分组标题、两个文本框、两个密码块（输入框加强度条和提示）、验证码、提交按钮共10个块，各自在越过上边缘或下边缘时淡出并位移，回来时从同一侧滑入。提交按钮外面包了一层容器来做动画，避免覆盖按钮自己的悬停过渡。
- **探针调整**：初始化页不再有描边卡片，`visual_probe.js`里原来用初始化页检查描边几何的步骤，改为在公开首页的第一个描边表面（首页英雄卡片）上检查，检查内容不变。

## 1.46.0 的改动

- **文案改朴素**：说明改成“先给站点建一个管理员账号，之前的管理员凭证已经不能用了。建好就直接进后台，这个页面以后不会再出现。”；卡片副标题改成“只存在你自己的数据库里，密码是加密保存的。”；提示语改成口语：“3 到 50 个字符，登录时用”“字母、数字、符号混着用更好”“再输一遍，防止打错”“两次一样/两次不一样”“很不错”。
- **左侧占比更大**：整体宽度1080→1200，左右两栏比例由约0.9:1.05改为1.15:1；标题放大；小云不再放在卡片里，直接站在页面上，宽度放大到约380px，并裁掉了多余留白，使它和文字左对齐。去掉了白底、边线和内边距。手机和平板仍隐藏小云。
- **文本框滚动入场/出场**：每个文本框（五个输入字段和验证码托盘）在越过页面上边缘或下边缘时，朝它离开的那一侧淡出并位移28px，回来时从同一侧淡入滑回；向下滚动是从下方进入，向上滚动是从上方进入。用`IntersectionObserver`实现，一开始就在视口里的框不会闪动；减少动态或低性能模式下不启用，所有框保持可见。实现时发现属性名`data-reveal`与站点原有的滚动显现系统冲突（会把元素默认设为透明），改用专用的`data-setup-reveal`。

## 1.45.0 起的样式：简洁、可爱

- **整体**：白色卡片、细浅蓝线、浅粉浅蓝的点缀，和站点其他页面保持同一种语言。输入框、按钮、验证码托盘都用站点主题的统一样式，不再有自己的凹凸阴影；页面里没有任何内阴影或双向阴影（有测试守着）。
- **去掉的AI味元素**：左侧叠放漂浮的骨架卡片、指针视差、“第一次启动”徽章、英文眉题和图标方块、绿色以外的高光和模糊入场。
- **可爱的部分**：左侧一朵会眨眼的小云（呼应“云迹”），随表单进度变化：三步都完成后嘴巴变成笑脸、脸颊更粉，下方状态从“管理员待创建”变成“可以创建了”。手机和平板上小云隐藏，只保留步骤。
- **易懂**：一个标题“创建唯一管理员”和两句说明；左侧三步清单随填写进度点亮、打勾，出错时指向出错的那一组；表单分“账号 / 密码 / 验证”三组，字段和服务端规则不变。密码框有显示/隐藏、“还差N个字符”提示和四段强度条，确认密码实时提示是否一致。
- **动画**：入场依次轻轻上浮；步骤圆点、连线、对勾、强度条和按钮箭头用短过渡；提交后按钮变成三点加载状态。减少动态或低性能模式下所有动画停止。
- **布局**：桌面双栏、左侧随页面固定；平板和手机单列，步骤改成横向三点。

## 修复与行为

- 服务端校验失败时，不回显密码，也清空已经失效的验证码答案；保留用户名。
- 之前已有：动效描边默认色 #D4E6F3，旧默认值（#91BED8、#BFD9E8）读取时视为未自定义并换新默认，不改数据库。

## 验证

- pytest 227个通过，Ruff通过。新增的前端契约守住：页面里没有内阴影/双向阴影、提交按钮使用站点统一的主按钮、前端密码最小长度与服务端规则一致、减少动态规则存在。
- 初始化页浏览器端到端（8种宽度：320、360、390、768、1024、1280、1440、200%缩放）：无横向溢出、无元素越界、输入框宽度足够、描边画完、控制台为空；减少动态下没有运行中的动画；Tab 顺序为 用户名→显示名称→密码→显示密码→确认密码→换验证码→验证码→提交；故意输错确认密码时错误出现在对应字段；正确提交后进入后台并出现成功提示。
- 初始化页计算样式审计：线条与填充里的蓝色只有有意保留的浅灰蓝 #99abcd 和键盘焦点环；输入框没有内阴影。
- 完整`visual_probe.js`与全站443次页面审计结果见会话记录；新增的开场入场用单独脚本在桌面、手机、关闭脚本三种情况下验证：打开后10个入场动画同时在运行，可见的块一度为全透明，随后全部落定为完全不透明、没有残留动画；减少动态下一次性显示。滚动入场出场用单独的浏览器脚本验证（10个块）：屏幕外的框等待在下方、进入视口后完全显现、向上滚动能抓到渐变的中间帧、滚过上边缘的框从上方离开，减少动态下没有任何框被隐藏。
- 截图和报告在`session-data/qa/v1.48.0-setup-entrance`；人工看了初始化页桌面（初始、填写中、可提交）、平板、手机的截图，其余页面靠自动检查。
- verify-web-visuals Skill在当前环境不存在，用Playwright与上述脚本代替。

## 没有做的

- 初始化页没有分成多步翻页，一页三组更容易看到全部要填什么。
- 一次性初始化口令只能在页面里提示命令名，没有页面内签发。
