# 动效与降级规范

## 1. 动效目标

动效用于解释层级、确认操作和建立柔软可爱的触感。任何动画都不能延迟内容阅读、表单提交或导航。

关键词：轻、软、短、自然停止。

## 2. 时间变量

| Token | 时长 | 用途 |
| --- | --- | --- |
| `--duration-instant` | 100ms | 按下、颜色反馈 |
| `--duration-fast` | 160ms | 按钮、标签、提示 |
| `--duration-normal` | 240ms | 卡片、下拉、局部切换 |
| `--duration-slow` | 360ms | 抽屉、弹窗、页面进入 |
| `--duration-decorative` | 600ms | 一次性装饰进入上限 |

连续悬浮装饰周期建议6～10秒，最多只在少量元素上使用。

## 3. 缓动变量

```css
--ease-standard: cubic-bezier(.2, .8, .2, 1);
--ease-enter: cubic-bezier(.16, 1, .3, 1);
--ease-exit: cubic-bezier(.4, 0, 1, 1);
--ease-spring-soft: cubic-bezier(.2, 1.25, .35, 1);
```

CSS弹簧曲线只用于小幅缩放和位移。涉及拖拽或高度变化时，使用可中断的Web Animations或即时状态切换，避免多个动画互相争夺。

## 4. 组件动效

### 按钮

- 悬停：上移1px或背景加深，160ms。
- 按下：缩放0.97，100ms。
- 成功：图标一次轻弹，整体按钮不移动。

### 卡片

- 悬停：上移3px，阴影从`sm`到`md`，240ms。
- 按下：缩放0.985。
- 卡片内部图片最多缩放1.02，不产生明显裁切跳动。

### 菜单与抽屉

- 胶囊菜单展开：宽度/内容通过transform和opacity组合，240ms。
- 抽屉进入：移动20～32px并淡入，360ms。
- 菜单项可错峰，但总错峰时间不超过120ms。

### 弹窗

- 遮罩160ms淡入。
- 容器从0.98缩放到1并上移归位，240ms。
- 退出更快，约160ms。

### 页面

- 服务端页面切换不阻止浏览器默认导航。
- 新页面主内容从8～12px下方淡入，最长360ms。
- 浏览器后退时优先恢复滚动位置，不重复大面积进入动画。

## 5. 滚动与物理效果

- 阅读页不使用滚动劫持。
- 目录高亮即时或短过渡，不能延迟当前章节反馈。
- 视差只在支持hover、无减少动画、性能允许的桌面设备启用，最大位移约8px。
- 卡片倾斜最大1.5度，鼠标离开立即柔和归位。
- 拖拽排序使用占位、吸附和明确落点，键盘提供上移/下移替代操作。

## 6. 性能规则

- 优先动画`transform`和`opacity`。
- 不持续动画宽高、边距、阴影模糊、滤镜或背景位置。
- 同一视口最多3个持续装饰动画。
- 使用`will-change`只在动画前短暂设置，不全局常驻。
- 页面隐藏时暂停持续动画。
- 低端设备检测到长任务时关闭装饰动画，不影响反馈动画。

## 7. 减少动态效果

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    scroll-behavior: auto !important;
    animation-duration: .01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: .01ms !important;
  }
}
```

除系统设置外，站点设置菜单提供“跟随系统 / 减少 / 完整”选项。用户选择保存在本地浏览器中，不需要外部服务。

减少模式下：

- 关闭视差、漂浮、倾斜、错峰和弹簧过冲。
- 菜单、抽屉和弹窗保留即时显示/隐藏。
- 加载进度仍显示，但不使用循环旋转，可改为静态文字或进度条。
- 成功、错误和当前状态仍通过图标、文字与颜色表达。

## 8. 动效验收

- 动画可被新操作中断，不排队造成延迟。
- 快速连续点击不会产生状态错乱。
- 60Hz设备上的关键交互无明显掉帧。
- 减少动态效果生效后核心流程完全可用。
- 键盘与触控操作获得等价反馈。
- 动画结束后焦点、滚动和DOM状态正确。
