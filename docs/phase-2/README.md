## 可交互原型

- [原型入口](prototype/index.html)
- 原型包含：首页、博客列表、文章详情、关于我、友链和后台仪表盘。
- 原型只使用本地HTML、CSS和JavaScript，不加载远程字体、图标、图片或脚本。
- 通过顶部原型切换器预览不同页面，通过浏览器宽度预览桌面、平板和移动布局。

## 主题结论

- 主题名：云朵手账（Cloud Diary）。
- 视觉关键词：轻盈、柔软、清澈、手账感、克制的可爱。
- 主色：雾蓝；辅助色：樱粉、薰衣草紫、薄荷绿和暖黄。
- 形状：大圆角卡片、胶囊按钮、圆形状态点和不规则贴纸装饰。
- 动效：短促弹性反馈、轻微浮动、分层进入和明确的减少动态效果降级。

## 原型边界

原型用于确认视觉与交互方向，其中内容均为演示数据。阶段三将依据这些变量、组件和布局规则建立Flask/Jinja2项目骨架；不得直接把原型中的静态页面当成最终业务实现。
