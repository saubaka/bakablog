# 核心页面线框与内容层级

以下线框用于确定层级与响应式顺序，视觉细节以静态原型和设计系统为准。

## 1. 首页

```text
┌──────────────────── 悬浮胶囊导航 ────────────────────┐
│ 标识  首页  博客  项目  动态  相册  友链  关于  搜索 │
└──────────────────────────────────────────────────────┘

┌───────────────────────┐  ┌───────────────┐
│ 欢迎卡：头像/标题/签名 │  │ 当前状态      │
│ 主操作 + 社交入口      │  ├───────────────┤
│ 云朵/贴纸局部装饰      │  │ 今日小记      │
└───────────────────────┘  └───────────────┘

┌─────────────────────────────┐  ┌───────────┐
│ 精选文章                    │  │ 项目/动态 │
│ 大文章卡 + 两张紧凑文章卡   │  │ 快捷预览  │
└─────────────────────────────┘  └───────────┘

┌──────────────── 相册预览 ─────────────────┐
└───────────────────────────────────────────┘
┌──────────────── 友链星球 ─────────────────┐
└───────────────────────────────────────────┘
```

移动顺序：导航头 → 欢迎 → 状态 → 精选文章 → 项目 → 动态 → 相册 → 友链 → 页脚 → 底部导航。

## 6. 后台仪表盘

```text
┌──────────┬────────────────────────────────┐
│ 侧栏导航 │ 顶部：页面名 / 搜索 / 新建 / 用户│
│ 仪表盘   ├──────┬──────┬──────┬──────────┤
│ 内容     │ 文章 │ 草稿 │ 审核 │ 访问摘要 │
│ 个人     ├───────────────────┬────────────┤
│ 媒体     │ 最近内容与快捷操作│ 待处理事项 │
│ 互动     ├───────────────────┼────────────┤
│ 外观     │ 系统状态          │ 最近操作   │
│ 系统     │ SQLite/备份/媒体   │            │
└──────────┴───────────────────┴────────────┘
```

移动端侧栏变为抽屉；统计卡2列或单列；表格以卡片列表表达优先信息。

## 7. 内容优先级

一级：页面标题、正文、主操作、导航、错误与审核状态。

二级：摘要、封面、分类标签、时间、进度和辅助操作。

三级：贴纸、云朵、背景渐变、装饰性图标和趣味文案。

在空间不足、减少动态效果、高对比需求或加载失败时，必须先移除三级内容，再调整二级内容，一级内容不可隐藏。
