# 视觉设计系统

## 1. 主题语言

“云朵手账”把个人网站设计成一册漂浮在浅色天空中的数字手账。内容卡片像便签、信纸和拍立得，但信息层级、对比度和可操作性优先于装饰。

使用原则：

- 一屏最多出现两种明显装饰语言，避免同时堆叠云朵、星星、胶带和渐变。
- 可爱来自比例、圆角、色彩与细节，不使用幼稚或难读字体承载正文。
- 主要内容卡片保持白色或近白色；彩色背景只用于提示、标签和局部强调。
- 前台强调个性，后台强调效率，但两者共享相同设计变量和交互状态。

### 2.3 颜色使用

- 主操作使用`blue-100`至`blue-300`的浅蓝渐变表面，并搭配`blue-600`灰蓝文字；同一视口最多一个高权重主按钮。
- 浅蓝、浅粉、浅紫、浅绿、浅黄的文字必须使用各自深色文字，不在浅色底上使用白字。
- 正文链接使用`blue-600`灰蓝文字并保留下划线或其他非颜色提示。
- 禁用状态使用降低饱和度的背景，同时保留可读文字和禁用光标。
- 焦点环统一使用半透明雾蓝外环，在彩色背景上增加白色内环。

## 3. 字体

### 3.1 本地字体栈

```css
--font-sans: ui-rounded, "Microsoft YaHei UI", "PingFang SC",
  "Noto Sans CJK SC", system-ui, -apple-system, sans-serif;
--font-mono: "Cascadia Code", "SFMono-Regular", Consolas, monospace;
```

首发不强制打包额外字体，先使用系统字体栈。若阶段三引入本地字体，必须子集化、记录许可证并提供系统回退。

### 3.2 字号和行高

| Token | 桌面 | 移动 | 行高 | 用途 |
| --- | --- | --- | --- | --- |
| `display` | 52px | 36px | 1.12 | 首页主标题 |
| `h1` | 40px | 30px | 1.2 | 页面标题 |
| `h2` | 30px | 25px | 1.28 | 大章节 |
| `h3` | 22px | 20px | 1.35 | 卡片标题 |
| `body-lg` | 18px | 17px | 1.75 | 文章导语 |
| `body` | 16px | 16px | 1.75 | 正文与表单 |
| `small` | 14px | 14px | 1.5 | 元信息 |
| `caption` | 12px | 12px | 1.45 | 标签和辅助信息 |

正文不使用小于16px的基础字号。文章行宽为每行约36～44个中文字符。

## 4. 间距和尺寸

基础间距序列：`4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80`px。

| Token | 值 | 用途 |
| --- | --- | --- |
| `--space-page-x` | `clamp(16px, 4vw, 48px)` | 页面水平留白 |
| `--space-section` | `clamp(48px, 7vw, 88px)` | 前台章节间距 |
| `--space-card` | `clamp(18px, 2.5vw, 28px)` | 普通卡片内边距 |
| `--control-sm` | `36px` | 紧凑后台控件 |
| `--control-md` | `44px` | 普通按钮与输入框 |
| `--control-lg` | `52px` | 主要胶囊操作 |

所有触控操作目标至少44×44px；视觉图标可以更小，但可点击容器不能缩小。

## 5. 圆角与轮廓

| Token | 值 | 用途 |
| --- | --- | --- |
| `--radius-sm` | `10px` | 标签和小控件 |
| `--radius-md` | `16px` | 输入框和普通卡片 |
| `--radius-lg` | `24px` | 主卡片 |
| `--radius-xl` | `32px` | 首页大型容器 |
| `--radius-pill` | `999px` | 胶囊按钮和状态 |

卡片圆角不能嵌套得过于接近：外层32px时内层建议20～24px。边框优先使用1px浅色实线，选中态使用2px或内描边避免布局跳动。

## 6. 阴影与层级

```css
--shadow-xs: 0 1px 2px rgba(61, 82, 110, .06);
--shadow-sm: 0 8px 24px rgba(93, 119, 154, .08);
--shadow-md: 0 18px 45px rgba(93, 119, 154, .12);
--shadow-float: 0 24px 60px rgba(93, 119, 154, .16);
```

- 普通卡片使用边框加`shadow-xs`或无阴影。
- 悬浮菜单、弹窗和抽屉使用`shadow-md`或`shadow-float`。
- 不通过不断增加阴影表达层级；遮罩、位置和边框也参与区分。

层级建议：页面0、悬浮导航20、下拉菜单40、遮罩60、抽屉70、弹窗80、通知90。

## 7. 图标和插画

- 图标统一使用2px圆角线条，默认20～22px。
- 图标必须配合可访问文本或`aria-label`，不能让访客猜含义。
- 装饰SVG使用`aria-hidden="true"`。
- 头像和封面没有图片时使用本地渐变、首字或简单几何插画占位。
- 贴纸装饰最多占卡片面积10%，且不能覆盖文字或操作区。

## 8. 前后台密度

前台：更大的章节间距、24～32px圆角、非对称卡片和柔和装饰。

后台：保留颜色、圆角和图标风格，但使用16px卡片圆角、36～44px控件、紧凑表格和固定操作区。后台不能为了可爱降低信息扫描效率。
