# 组件与状态矩阵

## 1. 状态基线

所有可交互组件至少评估以下状态：默认、悬停、按下、键盘焦点、禁用、加载、成功、错误。只读展示组件还需评估空内容、内容过长、图片缺失和离线资源缺失。

## 2. 通用状态规则

| 状态 | 视觉 | 行为 |
| --- | --- | --- |
| 默认 | 清晰边框与可读标签 | 可操作 |
| 悬停 | 轻微颜色或位移变化 | 仅在支持hover设备启用 |
| 按下 | 缩放0.97～0.99、阴影收紧 | 不改变布局尺寸 |
| 焦点 | 2～3px雾蓝焦点环 | 键盘焦点始终可见 |
| 禁用 | 低饱和背景与文字 | 不响应点击，不接受焦点或明确说明 |
| 加载 | 保留原尺寸，显示进度 | 防止重复提交 |
| 成功 | 绿色图标+文字 | 简短确认，不只变色 |
| 错误 | 红色边框+说明+修复建议 | 焦点移至首个错误或错误摘要 |

## 3. 按钮

类型：主按钮、次按钮、柔和按钮、危险按钮、图标按钮、文本按钮。

- 主按钮每个操作区域只保留一个。
- 图标按钮最小44×44px并提供名称。
- 加载时宽度保持稳定，文字可保留并附加进度图标。
- 危险操作默认使用次级外观，确认弹窗中才使用危险主色。
- 禁用按钮必须说明原因时，使用旁边的帮助文本，不能依赖悬停提示。

## 4. 导航

- 当前项同时使用背景、文字权重和`aria-current`。
- 桌面胶囊菜单展开后焦点进入首个菜单项，Escape关闭并归还焦点。
- 移动底部导航固定五项，“更多”打开抽屉。
- 页面切换加载进度不阻塞点击，也不模拟虚假长时间加载。

## 5. 卡片

类型：文章、项目、动态、照片、友链、统计、设置和空状态卡。

- 可点击整卡必须使用合法链接结构，不能嵌套冲突按钮。
- 悬停上浮不超过4px，触控下按压缩放不超过0.98。
- 图片缺失时显示本地渐变占位和类型图标。
- 标题最多按页面需求限制行数，正文摘要截断后仍提供完整可访问名称。
- 选中态使用边框与勾选标志，不仅改变背景。

## 6. 表单

组件：文本输入、多行文本、选择、复选、开关、日期、上传、搜索和标签输入。

- 标签位于输入框外，不使用占位文字代替标签。
- 帮助文本和错误文本通过可访问属性关联。
- 错误状态保留用户输入。
- 必填字段使用文字或符号并提供统一说明。
- 开关只用于立即生效或明确保存的二元状态；危险状态使用复选确认。
- 文件上传显示允许格式、大小、预览、进度和失败原因。

## 7. 弹窗、抽屉和浮层

- 普通确认、简短编辑使用弹窗；复杂筛选和移动菜单使用抽屉。
- 打开时锁定背景滚动并把焦点移入；关闭时恢复触发点焦点。
- Escape可关闭非强制弹窗。
- 点击遮罩关闭只作为辅助，不替代明确关闭按钮。
- 不使用多层弹窗；需要进一步操作时替换当前内容。

## 8. 反馈

### Toast

- 用于保存成功、复制成功等非阻塞结果。
- 最长显示约5秒，重要错误不能只用自动消失Toast。

### 页面提示

- 信息、成功、警告、错误均使用图标、标题和文字。
- 错误提示给出重试、返回或联系管理员等下一步。

### 骨架屏

- 形状近似真实内容，不使用大面积闪烁。
- 仅用于预计超过约300ms的局部异步加载。
- 服务端首屏正常情况下不显示骨架屏。

### 空状态

- 包含简短原因、下一步操作和可选轻量插画。
- 后台首次使用空状态提供“新建”入口。
- 搜索无结果提供清除筛选和推荐入口。

## 9. 内容组件

- 文章目录：当前章节高亮，移动端可折叠。
- 代码块：语言、复制按钮、横向滚动和清晰焦点。
- 图片灯箱：键盘切换、关闭、焦点管理和图片说明。
- 标签：非交互标签和筛选按钮外观需区分。
- 分页：保留上一页/下一页，当前页有可访问说明。
- 评论：层级最多两级视觉缩进，更深回复扁平化并引用对象。

## 10. 后台组件

- 数据表：列排序、筛选、选择、批量操作、空状态和错误状态。
- 编辑器：标题、正文、元数据、预览与粘性发布操作区。
- 状态徽章：草稿、定时、发布、归档、待审核、垃圾各有文字。
- 统计卡：数值、趋势、时间范围和跳转入口，不能只有装饰图表。
- 危险区：与普通设置分组，使用明确说明和二次确认。

## 11. 组件验收清单

- 320px宽度和200%缩放下无关键内容截断。
- Tab顺序符合视觉顺序。
- Enter/Space行为符合控件语义。
- 错误状态可被屏幕阅读器识别。
- 触控目标不小于44px。
- 减少动态效果下没有必要操作丢失。
- 长中文、长英文、空值和图片失败都有设计。
