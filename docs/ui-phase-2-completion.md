# UI专项第二阶段完成记录

完成日期：2026-07-16  
应用版本：1.3.0

## 首页2.0

- 首屏升级为主介绍纸张、头像星球、状态卡和本地时间组成的非对称布局，并支持短标签及三级行动入口。
- 新增站点速览、1大2小精选文章、项目展柜、动态便签时间线、相册胶片、关于拼贴、友链/留言与页尾CTA。
- 文章、项目、动态、照片、友链和留言没有内容时均提供独立空状态；文章等内容区同时区分空、单条和多条状态。
- 首页使用文章/项目/动态/相册联合统计，并加入15秒进程内内容缓存；后台成功写入会立即清空缓存。

## 后台一一对应

- “首页与导航”现在管理首屏标题、说明、标签、状态、三级按钮、速览项目及顺序、关于短字段、CTA和页脚。
- 首页模块由5个扩展至9个；每项可配置标题、排序、数量、样式和启用状态。
- 旧SQLite实例无需结构迁移：公开页读取时补齐缺失默认模块，首次进入后台时把新模块持久化，同时保留已有模块配置。
- 链接继续使用协议白名单校验，后台配置不会引入任意脚本地址。

## 物理动效与降级

- 按钮支持指针按下、取消和释放回弹；图标、阴影和高光同步变化，触屏与鼠标共用状态控制。
- 可交互卡片支持明显按压、柔和悬停和桌面最大0.7度指针倾斜，离开时可中断回正。
- `IntersectionObserver`负责一次性模块进入和统计计数；同组错峰不超过220ms，浏览器后退恢复不重播大幅位移。
- 站内精简动效、系统减少动态和低性能模式都会关闭进入位移、倾斜、计数追赶和持续轨道动画。
- 桌面导航增加柔和滑动底板；手机菜单仍保持统一状态机、焦点约束与滚动锁。

## 验证证据

- pytest：91项通过。
- Ruff检查与格式检查、JavaScript语法检查、`pip check`全部通过。
- 首页热缓存请求数据库查询不超过1次；自动化覆盖空、单条、多条三种内容状态。
- Chromium在1440×1000、768×900、390×844和320×700检查通过：九模块均存在，无横向溢出、控制台警告或远程必需资源。
