# 阶段四交付物：数据库、登录与后台基础

阶段四已经把阶段三的后台界面骨架升级为真实的本地管理基础。项目现在具备 SQLite 数据库迁移、管理员登录、角色权限、媒体库、操作审计、登录日志、健康接口以及数据库与媒体联合备份能力。

## 已交付能力

- SQLAlchemy 模型与 Alembic/Flask-Migrate 迁移。
- SQLite 外键、WAL、繁忙超时和短事务基础策略。
- 无公开注册入口的本地管理员账号体系。
- 密码哈希、登录/退出、持久会话、CSRF 防护和安全跳转校验。
- 角色与细粒度权限的服务端拦截。
- 真实数据后台仪表盘、用户角色页、媒体库和审计日志页。
- JPEG、PNG、WebP 内容识别、像素限制、元数据清理与 WebP 缩略图。
- 统一 JSON API 成功/错误格式。
- SQLite 完整性、外键、并发等待、迁移与备份自动化验证。
- 数据库与本地上传目录的联合 ZIP 备份和带安全副本的离线恢复。

## 后台路由

| 路由 | 权限 | 用途 |
| --- | --- | --- |
| `/bakaadmin` | 公开但不展示入口 | 超级管理员登录 |
| `/admin/logout/` | 已登录 | POST 安全退出 |
| `/admin/` | `dashboard.view` | 真实数据仪表盘 |
| `/admin/media/` | `media.view` / `media.manage` | 图片上传、浏览与删除 |
| `/admin/users/` | `users.view` | 查看管理员与角色 |
| `/admin/audit-logs/` | `audit.view` | 查看操作和登录日志 |
| `/admin/api/status/` | `dashboard.view` | 统一格式的后台状态接口 |
| `/media/<path>` | 公开 | 提供已登记的本地媒体文件 |

## 阶段边界

本阶段只提供内容管理系统的基础设施。文章、分类、标签、编辑器、发布状态、博客搜索、归档、RSS 和站点地图将在阶段五实现。后台当前不会提前创建虚假的文章 CRUD。
