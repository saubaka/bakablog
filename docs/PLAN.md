## 0. 摘要

一个只有「首页 / 博客 / 动态」三块前台、访客完全不能写入（没有评论、留言、点赞、账号）的个人博客。
Flask 提供 JSON API，Vue 3 做前台和后台两个互相独立的入口，SQLite 单文件存数据。
视觉是极浅蓝、浅灰、浅粉的「手账」风格，没有任何深色块；所有文字和容器都随滚动位置实时入场、退场。

| 项 | 目标 |
|---|---|
| 前台 | 首页、博客（列表 / 详情 / 归档 / 分类 / 标签 / 系列 / 搜索）、动态、独立页面、RSS、站点地图 |
| 明确不做 | 评论与留言、访客账号、点赞、第三方登录、暗色模式、多语言、CDN、第三方统计脚本 |
| 运行 | 一台小机器、一个 gunicorn、一个 SQLite 文件；没有 Redis、Celery，也没有常驻 Node |
| 前台体积 | 首屏 JS ≤ 90 KB（gzip）、CSS ≤ 20 KB、字体 ≤ 30 KB；后台代码不会进入前台包 |
| 性能 | 移动 4G 下 LCP ≤ 2.0 s、CLS ≤ 0.05；滚动动效脚本每帧 ≤ 4 ms |
| 浏览器 | Safari / Chrome / Edge / Firefox 近两个主版本，iOS 16+ |
| 验收 | Chromium + WebKit（Safari 引擎）自动化，再加你本机 Safari 与手机实机 |

## 1. 范围与设计原则

### 1.1 前台功能一览

| 区块 | 内容 |
|---|---|
| 首页 | 由后台配置的模块：开场、精选文章、最新文章、最新动态、分类书架与标签贴纸、关于卡片、近况便签、公告 |
| 博客 | 列表（分类 / 标签 / 系列 / 搜索筛选）、文章详情（目录、阅读进度、系列导航、上下篇、相关文章）、归档、标签页、分类页、系列页 |
| 动态 | 时间线信息流：文字、最多 9 张图、心情贴纸、链接卡片、标签；单条永久链接；按月 / 标签 / 心情筛选 |
| 其他 | 独立页面（关于、友链、使用说明等）、搜索浮层、404 / 500、RSS（文章、动态各一个）、sitemap、robots |

### 1.2 反「AI 味」清单（写进设计评审）

1. 不用渐变底、玻璃拟态、发光、彩色或灰色阴影、大面积模糊。
2. 不用 emoji 当图标，不用通用图标库；自绘约 40 个线性图标（1.6px 圆头线，几何略不对称）。
3. 不做「居中大标题 + 副标题 + 两个按钮」的模板首页，不做「三列图标特性卡」。
4. 文案不写「欢迎来到我的数字花园 / 探索 / 赋能」这类话；占位文案写具体、有性格的短句；空状态讲人话。
5. 版面不全对称：窄标签列 + 宽内容列；卡片尺寸交替；少量元素倾斜 ±2°。
6. 只有一套造型语言：线、浅色填充、胶带、邮戳、便签、气泡，不混别的风格。
7. 动效克制：位移小、不回弹、没有 3D 翻转、没有无限循环闪烁。

### 1.3 从上一个项目带过来的硬规则

- **只有一种线色**：1px `#dceaf7`，卡片和容器一律扁平、没有阴影。上一个项目里线「看着深」，真正原因是卡片外圈的灰蓝阴影，不是线的颜色。
- **页面主容器永远不画聚焦环**：路由切换后脚本会聚焦 `<main>`，如果画了环就是一圈粗线，在屏幕顶部常驻、中部闪现。
- **所有 CSS 放进同一套有序的 `@layer`**，不混用分层与非分层样式（上一个项目里层与层的优先级把规则压反了）。
- **导航指示器只朝一个目标走一次**：先算好终点位置，再动；不能先飞向点击位置、换页后再折返。
- **站点名、作者名、默认文案只在一处定义**（设置表 + 一个文案文件），不在模板里写死，改名只改一处。
- **构建产物带内容哈希，`index.html` 不缓存**：避免浏览器一直用旧样式。页脚和 `/api/health` 显示版本号，每阶段完成后核对「你实际在用的那份服务」。
- **验收看截图，不只看自动化通过**：三个宽度截图 + WebKit + 你本机 Safari。

## 3. 滚动动效系统（重点）

### 3.1 原则：进度绑定滚动位置，而不是触发一次

不是「元素进入视野就播放一段 0.6 秒动画」，而是元素入场 / 退场进度的**目标值**是滚动位置的函数：滚一点动一点，停下就停住，反向滚就倒放。好处：任何跳转（锚点、前进后退、旋转屏幕、快速甩动）之后，终点都由当前位置直接算出来，不会卡在半透明。

**2026-10-24 补充：显示值有最短变化时间（见 3.2 末尾）。** 目标值仍然是位置的函数，但屏幕上显示的进度以有限速度追赶目标：一次完整的出现或消失（0 → 1 或 1 → 0）至少要 420 ms，所以大幅度滚动、快速甩动、锚点跳转都不会让元素瞬间出现或消失；慢慢滚时追赶速度够快，显示值与目标逐帧完全一致，和以前没有区别。

### 3.2 进度定义

设视口高度为 `vh`，元素矩形为 `rect`：

- 入场进度 `in = clamp((0.94·vh − rect.top) / (0.30·vh), 0, 1)`：元素顶边越过视口 94% 处开始，到 64% 处完成。
- 退场进度 `out = clamp((0.16·vh − rect.bottom) / (0.16·vh), 0, 1)`：元素底边进入视口顶部 16% 区域开始，到离开屏幕完成。
- 缓动：`ease(t) = 1 − (1 − t)³`。
- 同一行的并列元素按列序错开：`t_i = clamp((in − 0.08·i) / (1 − 0.08·(n − 1)))`，`i` 最大取 5。
- 高于视口 90% 的超高元素（长图、长代码块）：只做淡入，**不做退场**，避免阅读中途闪烁。
- 完全可见区（`in = 1` 且 `out = 0`）内的元素没有任何变换，保证阅读与截图一致。
- **最短变化时间**：上面算出的是目标 `tin / tout`（未缓动）。显示值 `lin / lout` 每帧朝目标走一步，步长不超过 `Δt / 420 ms`（`Δt` 是距上一帧的时间，超过 50 ms 按 50 ms 算，所以隐藏标签页回来、长任务都不会一步走完），再套上缓动写进 `--fx-in / --fx-out`。慢滚时目标每帧的变化小于步长，`lin === tin`；甩动或跳转时目标一步跳到终点，显示值要走满 420 ms，并且途中可以随时被新的目标掉头（从当前值平滑反向）。
- **入场的范围（2026-10-24 补充）**：不只是页头。页面在顶部打开时，首屏上所有新出现的内容都入场——页头先，其余从上到下、从左到右依次跟上；文章正文这类稍后才到的内容算同一次打开；之后自己出现的内容有快速入场；折叠线以下的随滚动进来。离开页面时每一块内容各自向上淡出。全站每一块内容都必须带动效，由 `qa/coverage.mjs` 检查。
- 两种情况直接到位、不走过渡：元素的**第一张画面**（页面在顶部打开时除外，它们走上面的入场）（刚打开的页面不能从无到有地动一遍）和**获得焦点的元素**（不能是透明的，否则键盘用户看不见焦点）。焦点离开后它会平滑地回到该有的状态。
- 视差 `drift` 只是 ≤ 26 px 的位移，没有出现 / 消失，所以不受限速；`spine`（时间线脊线）和其它进度一样受限速。

### 3.3 动效类型

| 类型 | 入场 | 退场 | 用在哪里 |
|---|---|---|---|
| 上浮 `rise` | 下移 28px → 0，透明 0 → 1，缩放 .985 → 1 | 上移 0 → −20px，透明 1 → 0 | 卡片、文章行、面板 |
| 淡入 `fade` | 下移 12px → 0，透明 0 → 1 | 同上反向 | 段落、列表项、说明文字 |
| 弹出 `pop` | 缩放 .86 → 1，旋转 ±3° → 0，透明 | 缩小淡出 | 标签贴纸、徽标、便利贴 |
| 侧滑 `slide` | 横移 ±32px → 0 | 反向 | 动态气泡（左右交替时间线）、书架标签页 |
| 揭幕 `mask` | 圆角矩形裁切 `inset(8%)` → `inset(0)`，图片缩放 1.06 → 1 | 反向 | 封面、配图、拍立得 |
| 描线 `draw` | 线条 / 时间线脊线 scale 0 → 1 | 反向 | 分割线、动态时间线、标题下划线 |
| 逐字 `text` | 标题逐字上浮（按字错开） | 反向 | 页面标题、区块标题（≤ 32 字） |
| 轻视差 `drift` | 位置 = 偏移 × k（\|k\| ≤ 0.06），不改透明度 | — | 涂鸦、拍立得 |

另有两个与入场退场无关、但同样绑定滚动的元素：顶部 2px 的阅读进度线（浅粉，不是深色）和目录当前项指示器（只走一次）。

### 3.4 文字动效

- 标题（≤ 32 字）按字拆分，字间错开最多占总进度的 60%；西文按词包裹，避免词中断行。
- 拆分用 `Intl.Segmenter`（不支持则退回按码点），父元素保留完整 `aria-label`，每个 `span` 设 `aria-hidden`，读屏仍读整句。
- 正文段落不逐字拆分，整块做 `fade`；文章里每个顶层块（段落、列表、引用、代码、图片）各自独立。
- 手机上超过 24 字的标题自动降级为整行 `fade`。
- 风险点（第 9 节有对应验证）：逐字内联块在中文里的折行行为，要在 WebKit 与 Chromium 里实测；不合格就降级成按词 / 按行。

### 3.5 引擎设计

- 一个全局引擎：`Map<元素, 配置>` + `IntersectionObserver`（`rootMargin: 25% 0`）只维护「活跃集」，距离屏幕远的元素不参与计算。
- 滚动时 `requestAnimationFrame` 循环：先批量读取活跃元素的矩形，再批量写入 `--fx-in` / `--fx-out`（0–1 的自定义属性）和 `data-fx-state`；停止滚动 120 ms 后循环自动停止。
- CSS 里用 `transform` 与 `opacity` 引用这两个变量；`will-change` 只在状态为 active 时设置。
- 使用 `document.documentElement.clientHeight` 与 `ResizeObserver`，不依赖会随地址栏变化的 `innerHeight`；负的 `scrollY`（橡皮筋回弹）按 0 处理。
- Vue 接口：`v-fx="'rise'"`、`v-fx="{ type: 'pop', delay: 2 }"`、组件 `<FxText split="char">`、组合式 `useFxGroup()`（给一组元素自动分配错开序号）。
- 同时活跃元素上限 40，超出的按距视口中心的远近降级为纯淡入。
- 预算：中端手机（CPU 6 倍降速）每帧脚本 < 10 ms；常规设备 < 4 ms。
- 刻意**不依赖** CSS 的 `animation-timeline`（滚动驱动动画）：旧版 Safari 没有，所以只维护一套 JS 实现，行为一致。路由切换可选用 View Transitions 作增强，没有就退回 180 ms 交叉淡入。

### 3.6 降级与边界情况

| 情况 | 处理 |
|---|---|
| 系统「减少动态效果」或站点开关 | 所有类型的进度固定为 1，没有位移、缩放，只保留 120 ms 的透明过渡或完全无动画 |
| 无 JS / 爬虫 | 默认样式就是完全可见；`html.fx-ready` 由 JS 在引擎启动后才加上 |
| 打印 / 阅读模式 / 整页截图 | `@media print` 与 `.no-fx` 关闭所有变换 |
| 锚点跳转、前进后退、刷新恢复滚动位置 | 终点由位置直接算出，无「卡住」状态；过程用 420 ms 平滑过渡，不会瞬间出现或消失 |
| 窗口缩放、手机旋转 | `ResizeObserver` 触发整批重算 |
| 快速甩动 | 一帧内读写，不累积；显示值以每帧 ≤ Δt/420 ms 的速度追赶目标，终点一定正确，途中不瞬移 |
| 键盘聚焦到屏幕外元素 | 聚焦的元素强制 `in = 1, out = 0`，不能让聚焦项是透明的 |
| 页面首屏 | 开场区做一次时间驱动的入场（约 600 ms，错开），之后才进入滚动驱动 |

### 3.7 怎么验收动效

- Playwright 脚本分步滚动，采样若干元素的 `--fx-in` / `--fx-out` 与计算后的 `opacity / transform`：必须随位置单调变化，且位于视口中部时完全可见。
- 同一脚本覆盖锚点跳转、`scrollTo` 大跨度、模拟甩动、缩放、旋转、减少动效、前进后退；分别在 Chromium 与 WebKit 下跑。
- 最后在你的 Mac Safari 与 iPhone 上各手动过一遍（这是最终依据）。

## 4. 前台功能规划

### 4.1 站点骨架

顶栏（标志 + 站点名 + 搜索入口）、**滚动到页面最上 / 最下边缘继续滚，翻到菜单的上一项 / 下一项**（橡皮筋 + 弹簧，2026-10-24 按用户要求加，第一项的顶部和最后一项的底部不做；见 FRONTEND.md）、左边缘的针线菜单（手机和平板是贴底的针线栏）、页脚（只有一行：版权，有备案号时带备案号；品牌块和“浏览”“订阅与联系”两列已在 2026-10-24 按用户要求从所有页面删除）、搜索浮层（`/` 或 `⌘K` 呼出，带最近搜索）、回到顶部（箭头 + 滚动进度环）、阅读进度线、跳到正文链接。路由切换：回到顶部、焦点移到页面标题（`tabindex="-1"` 且**不画环**）、180 ms 交叉淡入。

### 4.2 首页

桌面（12 栏）：

1. **开场**：左 7 栏——小标签行（读自后台「近况」，如「今天在写…」）、两行大标题（逐字入场）、两行简介、按钮（读文章 / 看动态 / 订阅）；右 5 栏——倾斜 2° 的拍立得相框（头像或后台指定图片）、顶部一条胶带、日期邮戳，背后两个涂鸦做轻视差。
2. **最近的文章**：左侧窄标签列（区块名 + 「全部文章 →」），右侧——一张大卡（精选）、两张中卡并排、其余为紧凑列表行；卡片样式交替，不是一排一样的方块。
3. **最近的动态**：左侧标签列，右侧三条气泡（带图和心情贴纸）。
4. **书架**：分类做成文件夹标签页（带篇数），标签做成贴纸云（字号只在 3 档内变化）。
5. **关于我**：头像、简介、社交链接（圆形小按钮）、「近况」便利贴。
6. **结尾**：一句晚安 + 订阅 RSS + 页脚。

手机：单列；开场里拍立得叠在文字下方并缩小；区块标签变成区块上方的小标题；动态气泡占满宽度。

所有模块的顺序、显隐、文案、数量由后台「首页配置」决定（见 5.3）。

### 4.3 博客

- **列表**：顶部是「便签索引」——分类文件夹标签页 + 标签贴纸 + 搜索框 + 排序；卡片样式有四种，可按文章逐篇指定或按规则自动选：封面大图卡、左图右文、纯文字便签、引言卡（给很短的文章）；另有系列合集卡。分页用 URL 参数，页码是「翻页」样式；没有无限滚动（便于返回时恢复位置）。
- **详情**：封面（揭幕 + 轻视差）、逐字标题、元信息（日期邮戳、阅读时间、分类标签页、标签贴纸）；正文宽 720；桌面右侧粘性目录（当前章节指示器只走一次），手机是「目录」浮钮 + 底部抽屉；顶部浅粉阅读进度线；文末有系列导航、上一篇 / 下一篇（翻页卡）、相关文章（同标签）、可选的作者小卡片。**没有评论入口**，联系方式只放在关于页的社交链接与 `mailto`。
- **正文样式**：二级标题前一个小涂鸦；引用是便签气泡；提示块 4 种（提示 / 备注 / 小心 / 喜欢，浅蓝 / 浅灰 / 浅粉 / 白）；代码块浅灰底、1px 线、文件名页签、复制按钮，语法高亮用蓝、粉墨、灰墨三个系列（均 ≥ 4.5:1）；表格有横向滚动容器与浅色斑马纹；图片是图注图（可选拍立得框）；连续图片自动成图集（2–4 列，点击灯箱）；脚注与任务列表。
- **归档**：按年 / 月的时间线（描线脊线 + 日期邮戳）。
- **标签页 / 分类页 / 系列页**：标题区 + 文章列表；系列页有进度（第几篇 / 共几篇）与连载状态。
- **搜索**：浮层 + `/search` 页；文章、动态、页面分组显示，高亮命中片段。

### 4.4 动态

- 信息流单列（≤ 640 宽），桌面左侧粘性「月份索引 + 迷你日历（有动态的日子标点）」。
- 每条：头像泡 + 文字气泡（1px 线，圆角 22，固定的小尾巴）、心情贴纸、标签、相对时间（悬停 / 长按显示完整时间）。
- 图片排版：1 张大图（4:3）；2 张两列；3 张 1+2；4 张 2×2；5–9 张三列；点击进灯箱（左右切换、滑动、双指缩放、Esc 关闭）。
- 链接卡片：站点图标 + 标题 + 域名，点击新窗口打开。
- 单条有永久链接 `/moments/:id`（含 OG 信息，便于分享）。
- 筛选：月份、标签、心情；游标分页（「再看一点」按钮，不做无限滚动）。

### 4.5 其他

独立页面（模板：纯文、宽幅、带侧栏三种）、404 / 500（一句具体的话 + 最近文章）、RSS（文章全文 / 摘要可选，动态单独一个）、sitemap、robots、OG / Twitter 卡片、JSON-LD（`BlogPosting`）。

### 5.3 各模块功能

优先级：**P0** 首版必须，**P1** 首版后紧接着做，**P2** 以后再说。

**概览（仪表盘）**

- P0：统计卡（文章已发布 / 草稿 / 定时、本月动态、7 日访问、存储占用）；快捷入口（写文章 / 发动态 / 传图片）；待办提示（超过 7 天没动的草稿、即将发布的定时内容、缺封面 / 缺摘要 / 图片缺替代文字）；最近活动；系统健康（版本、磁盘、数据库大小、最近备份时间与结果）。

**文章**

- 列表（P0）：封面缩略、标题（带置顶 / 精选 / 系列徽标）、状态、分类、标签、发布时间（定时有标记）、更新时间、阅读量；筛选（状态、分类、标签、系列、日期、关键词）；排序；表格 / 卡片视图切换；行操作（编辑、预览、复制链接、复制为草稿、移入回收站）；批量（发布 / 转草稿、改分类、加标签、置顶、移入回收站）。
- 编辑器（P0）：
  - 主区：大标题输入、别名（自动由拼音生成，可手改，改动自动登记 301 重定向）、摘要（留空自动取前 120 字）、Markdown 编辑区 + 实时预览（桌面并排，手机分页签）；工具条（标题、粗体、斜体、删除线、引用、列表、任务列表、链接、图片、代码块与语言、表格、提示块、分隔线、脚注、图集）；粘贴 / 拖入图片自动上传并插入；字数、阅读时间；快捷键。
  - 右栏：发布（状态：草稿 / 已发布 / 仅链接可见 / 私密；发布时间，未来时间即为定时；置顶；精选；预览链接，带有效期令牌）、整理（分类、标签可当场新建、系列与序号）、封面（媒体库选择、替代文字、焦点位置）、样式（列表卡片样式、是否显示目录 / 阅读时间 / 作者小卡片）、SEO（标题、描述、分享图、规范链接）、版本历史（最近 20 个，可对比、可恢复）。
  - 自动保存：停顿 10 秒保存草稿到服务器，离开页面前提示未保存；保存状态可见。
- P1：从 Markdown 文件导入（含 front matter）、导出为 Markdown；批量重新生成摘要。
- 编辑器：计划写的是 CodeMirror 6；**实际实现用的是普通文本域 + 纯函数变换**（输入法、撤销和手机键盘上最稳，所有变换有单元测试；代价是没有语法高亮和行号）。换成 CodeMirror 只需要替换 `MarkdownEditor.vue` 这一个组件，详见 [ADMIN.md](ADMIN.md)。

**动态**

- P0：列表、编辑（同文章编辑器，字段精简）、别名、模板（纯文 / 宽幅 / 带侧栏）、是否进导航 / 页脚、状态、SEO。

- P0：主题预设（4 选 1）、装饰开关（胶带、涂鸦）、动效强度（标准 / 轻柔 / 关闭，作为访客默认值，访客自己的系统设置优先）、代码高亮（3 套浅色）、404 / 500 文案、站点信息（名称、简介、Logo、favicon）。

- P0：站点标题 / 描述 / 关键词、默认分享图、robots 规则、sitemap 选项、RSS（全文或摘要、条数）、规范域名。

**系统**

- 账号与安全（P0）：修改用户名 / 密码、可选 TOTP 二次验证、登录会话列表（设备、时间、一键下线）、登录历史、登录失败限速与临时锁定。

- 日志（P0）：审计日志（谁、何时、做了什么，只增不改）、登录日志。
- 系统状态（P0）：版本与构建哈希、运行时间、数据库与媒体占用、定时任务最近一次结果、「重建搜索索引 / 重新生成缩略图 / 清理缓存 / VACUUM」按钮。

**回收站**（P0）：文章、动态、页面、媒体的软删除；恢复、永久删除；30 天自动清理。

### 5.4 后台的交互与视觉

- 与前台同一套令牌与组件，但更密：卡片同样是白底 1px 线、无阴影、圆角 20；管理页不做滚动入场，只在列表首次加载时做一次轻微错开，**没有退场**。
- 导航药丸只朝一个目标走；分组展开 / 收起有高度动画。
- 表单：行内校验、提交后按钮显示加载态、失败时保留输入；危险操作用「浅粉」确认弹窗，写明后果。
- 所有保存给出可见反馈（提示条 + 页面内状态），不依赖用户猜。

### 5.5 权限与安全

- 首版单管理员（owner）。`admin_users.role` 字段预留，接口统一经过 `@admin_required`，以后加编辑者只需扩展权限表。
- 首次运行：访问 `/admin/setup`，凭服务器日志里一次性打印的口令创建管理员；创建后该页永久关闭。文案按公开项目写，不假设只有作者一个人使用。
- 登录：密码 scrypt 哈希；失败限速（IP + 用户名）；会话为随机令牌（数据库只存哈希），HttpOnly、SameSite=Lax、生产环境 Secure；所有写接口校验 CSRF 令牌。

### 6.5 关键流水线

- **Markdown**：保存时渲染并存 `content_html`；链接加 `rel="noopener noreferrer"`；图片改写为 `<figure>` + `srcset`，带 `width/height`；代码块用 Pygments 类名；标题生成锚点并提取目录；经 nh3 白名单清洗（只放行受控的 class）；预览接口与发布用同一条流水线，保证「所见即所得」。
- **图片**：见 5.3 媒体库；`/media/<hash>/<尺寸>.webp` 永久缓存。
- **搜索**：FTS5 `trigram` 分词，≥ 3 字用全文，1–2 字退回标题 / 摘要的 `LIKE`；保存内容时同步更新索引；返回 `snippet()` 高亮。
- **SEO 与首屏**：前端是单页应用，但 Flask 对每个路由返回带有正确 `<title>`、描述、OG、规范链接的 HTML，并把该路由的首屏数据内联成 JSON，再附一份语义化的文字版内容给爬虫和无 JS 用户；Vue 启动后直接使用内联数据，首屏不再多一次请求。

### 6.6 缓存与版本

- 构建产物文件名带内容哈希，`Cache-Control: public, max-age=31536000, immutable`；`index.html` 与 JSON 接口 `no-cache` + `ETag`（可 304）。
- 内容有任何写入时，`site_version` 加一，用来失效进程内的首页 / 分类计数缓存。
- 页脚与 `/api/health` 显示版本号和构建哈希。

### 6.7 安全清单

CSRF、严格 CSP（`script-src 'self'`；动效只通过 CSSOM 设样式，不用内联样式属性）、HTML 白名单清洗、上传校验（文件头、重新编码、体积与像素上限）、链接卡片抓取的 SSRF 防护（禁内网 / 回环地址、限大小与超时、不跟随跳转到内网）、登录限速、安全响应头、前台完全没有访客写入入口、全站不请求任何第三方域名。

## 8. 部署与运维

- 形态：Debian 12 一台机器——gunicorn（2 进程 × 4 线程）→ 反向代理（Nginx / OpenResty）；静态资源由反向代理直接提供；systemd 服务 + 一个每 5 分钟的定时器跑维护任务（实测这台机器上启动一次应用约 3 秒 CPU，所以不用每分钟）（备份、回收站清理、访问统计汇总）。
- 配置：环境变量文件（权限 600）：运行环境、密钥、站点网址、数据目录。
- 备份：每日 SQLite 在线备份 + 上传目录打包，保留 14 份；用 `deploy/restore-drill.sh` 做「恢复演练」（把备份恢复到临时副本并与清单对照，不碰线上），建议每月一次、每次改动备份代码之后也做；后台打不开时用 `flask --app app restore`。
- 发布脚本：本地构建 → 打包（**设置 `COPYFILE_DISABLE=1`，并在服务器上清掉 `._*`**，否则迁移工具会读到 macOS 垃圾文件）→ 上传 → 先备份代码与数据库 → 停服务 → 同步 → 迁移与自检（以 root 加载环境文件后用 `runuser --preserve-environment`，且不要用管道吞掉退出码）→ 启动 → 健康检查 + 公网页面检查 → 失败自动回滚。
- 实现与排练：`deploy/`（`deploy.sh` / `remote-update.sh` / `rollback.sh` / `restore-drill.sh` / `rehearse.sh` + systemd 与 nginx 材料）。`rehearse.sh` 在本机临时目录里走完首次安装、更新、四种失败更新的回滚、恢复演练，排练里发现并修复了三个真实问题（Python 环境不能搬家、bash 3.2 与 5 对 ERR trap 的行为不同、rsync 参数在 BSD 上不可用）。
- 可选：多阶段 Dockerfile（没做）。
- 开发：`make dev` 同时起 Flask（5000）与 Vite（代理 `/api`）；`make check` 跑全部审计与测试。

## 10. 风险与需要你确认的点

### 风险

| 风险 | 对策 |
|---|---|
| 逐字标题在中文里折行异常（尤其 Safari） | P0 就做实验；不合格降级为按词 / 按行 |
| 低端安卓滚动动效掉帧 | 活跃集上限 40、每帧预算监控、必要时在该设备上降级为纯淡入 |
| 非苹果设备没有圆体中文字 | 接受回落到无衬线；以后可以评估自托管圆体子集（体积代价大） |
| SQLite 多进程写入冲突 | WAL + `busy_timeout`；写入很少，足够 |
| 中文搜索 1–2 字查询 | FTS 之外用 `LIKE` 兜底 |
| 功能蔓延 | 首版只做 P0；P1 / P2 单独排期 |

### 需要你确认（括号内是默认值，不回复就按默认做）

1. **站点名、作者名、头像、一句话简介**（默认占位，上线前在后台改；代码里不写死）。
2. **吉祥物**（原默认「云团子」；2026-10-24 你决定不要任何云朵，吉祥物连同云朵涂鸦、云边分割线、云朵封面图案已从整个项目删除，不再有这一项）。
3. **作者**（默认单管理员；以后要加编辑者，数据结构已预留）。
4. **统计**（默认内置匿名统计，无 Cookie、不存 IP，可一键关闭；也可完全不做）。
5. **私密 / 密码文章**（默认只做「草稿、仅链接可见、私密（仅管理员）」，不做密码访问）。
6. **「没有深色调」的边界**（默认：正文用柔和墨蓝灰 `#46546a`，不用纯黑、不出现深色块；如果连文字也要更浅，对比度会掉到 4.5:1 以下，影响阅读，不建议）。
7. **部署**（默认沿用你现有的 Debian 服务器 + 反向代理；是否需要 Docker 镜像，默认不需要）。
8. **备案号 / ICP 展示位**（默认页脚留一个可选字段）。

确认这些（或直接说「按默认」）之后，先做 P0：静态样张和动效原型，给你三个宽度的截图和可以在你 Safari 里滚动试的页面。
