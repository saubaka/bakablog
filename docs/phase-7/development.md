# 阶段七开发与使用

## 前台流程

- `/links/`展示已通过友链、接收申请并返回不可猜测的申请编号；`/links/application/<code>/`查询审核状态。
- `/gallery/`和`/gallery/<slug>/`展示已发布相册。缩略图带固有宽高并懒加载，点击后从本地媒体路由打开原图灯箱。
- 已发布文章详情页接收评论与一级回复，公开评论可以点赞或举报；所有新访客评论默认等待审核。
- `/guestbook/`接收留言，只公开审核通过的内容与站长回复，邮箱不会输出到页面。

## 后台流程

- “友链管理”完成分类、新建、编辑、通过、拒绝、停用、删除和单条可用性检查。
- “相册管理”完成草稿/发布、批量图片上传、照片说明、排序、精选和移除。
- “互动审核”集中处理评论、举报提示、留言、置顶、屏蔽、垃圾标记、删除、站长回复与通知已读。
- 升级旧实例后运行`flask seed-permissions`同步Stage 7权限；全新`site-init`会自动同步。

## 边界

SQLite限流适合当前单机、读多写少部署，不是跨多机限流器。邮箱仅供后台联系。外部友链头像不会作为运行时图片加载，公开卡片使用本地文字头像，以维持无远程资源承诺。
