# 可爱UI、首页与文章编辑器全面完善清单

版本：1.0草案  
记录日期：2026-07-16  
适用项目：Cloud Diary Flask个人网站  
实施原则：全部资源本地化、Flask服务端渲染优先、SQLite单机存储、渐进增强、高性能与多设备兼容。

## 1. 本轮问题确认

以下问题均作为真实缺陷或明确体验债务处理，不再视为“个人审美差异”。

### P0：直接影响功能

- [ ] 修复文章阅读进度不显示或计算不准确。
  - 当前顶部进度条依赖文章元素`getBoundingClientRect()`和经验系数，短文章、长标题、目录高度、手机地址栏变化时都可能失真。
  - 目录卡片目前只有“阅读进度”文字，没有对应的可视进度组件。
  - 需要同时提供顶部细进度条、目录内百分比/进度条，并保证二者使用同一数据源。
- [ ] 修复三条杠菜单打开后只有模糊遮罩、看不到菜单内容。
  - 遮罩和抽屉显示目前分别切换，缺少统一状态机。
  - 抽屉缺少可靠的`overflow-y:auto`、动态视口高度、安全区和失败兜底。
  - 必须覆盖360、390、620、768、860 CSS像素以及浏览器缩放场景。
- [ ] 为文章图片提供真正可操作的编辑面板。
  - 当前编辑器只是Markdown文本框。
  - 上传图片后只插入一段`<img src="...">`字符串。
  - 无法直观看到图片、调整宽度、对齐、顺序、说明、裁切比例或焦点位置。

### P1：整体体验不足

- [ ] 首页从“模块顺序展示”升级为具有明确叙事节奏的个人主页。
- [ ] 重做按钮、表单、卡片、标签、提示、弹窗、菜单的视觉与交互状态。
- [ ] 建立统一而丰富的浅色配色分工，避免大片白色与少量蓝色造成单调。
- [ ] 清理仍呈直角或近似方块的控件、媒体容器、表格和后台局部区域。
- [ ] 提升点击反馈力度，让按下、释放、成功、失败都能被明显感知。
- [ ] 增加细腻但可关闭的进入、悬停、展开、切换和内容反馈动画。

### P2：完整度与个性

- [ ] 建立网站专属装饰语言，而不是只依赖圆角白卡片。
- [ ] 为首页、博客、项目、动态、相册、友链、留言和后台建立各自的视觉识别。
- [ ] 后台提供与前台新增模块一一对应的配置能力。
- [ ] 增加主题密度、装饰强度与动效强度设置，但不引入外部主题依赖。

## 2. 新的可爱主题定义

主题名称暂定为“云朵手账工坊”。可爱感来自柔软比例、层叠纸张、轻微不对称、局部彩色、细线图标和自然回弹，不依赖幼稚字体或过度堆叠贴纸。

### 2.1 视觉关键词

- 柔软：大圆角、胶囊控件、低对比边界、弹性按压。
- 手作：便签层、胶带角、虚线缝线、拍立得边缘、微小旋转。
- 清透：浅蓝天空底、粉色云霞、白色内容纸、浅灰分隔。
- 精致：1px内外双层线、局部高光、细颗粒纹理、统一图标线宽。
- 有节奏：不是所有模块都用相同三列白卡片；大卡、小卡、横向卡、时间线和胶片带交替出现。

### 2.2 色彩体系与分配比例

页面不再只使用“白底 + 蓝按钮”，而采用角色化颜色。

| 角色 | 建议色 | 用途 | 单屏建议占比 |
| --- | --- | --- | --- |
| 天空底色 | `#F5F9FD`、`#EEF7FF` | 页面背景和大区域雾蓝渐变 | 45%～55% |
| 纸张白 | `#FFFFFF`、`#FCFDFE` | 正文、表单和主要卡片 | 25%～35% |
| 云霞粉 | `#FCE8F0`、`#F6C9DA` | 收藏、精选、柔和强调 | 6%～10% |
| 湖水蓝 | `#F5FAFF`、`#DDEEFF`、`#A8D0F4` | 主操作表面、链接底板、焦点光环 | 6%～10% |
| 薄荷绿 | `#E2F5EA`、`#74B991` | 在线、完成、自然主题 | 3%～6% |
| 奶油黄 | `#FFF3D8`、`#E5B957` | 便签、提醒、置顶内容 | 3%～6% |
| 薰衣紫 | `#EEE9FF`、`#9681D1` | 项目、代码、创意内容 | 3%～6% |
| 文字灰蓝 | `#344054`、`#667085` | 正文与辅助信息 | 按可读性使用 |

规则：

- [ ] 每个页面最多设置一个主色、两个辅助色，避免平均撒色。
- [ ] 同一模块内部只使用一个主色族；颜色通过背景、图标、细线和标签形成层次。
- [ ] 主操作仍保持高辨识度，彩色卡片不能与主要按钮抢层级。
- [ ] 所有文字组合达到WCAG AA；不能用很浅的粉蓝文字表达必要信息。
- [ ] 后台增加模块色调选择：蓝、粉、薄荷、奶油、紫、自动轮换。

### 2.3 圆角规则

- [ ] 页面级大容器：32～40px。
- [ ] 首页主卡、抽屉、弹窗：28～34px。
- [ ] 普通内容卡：22～26px。
- [ ] 后台面板：18～22px。
- [ ] 输入框、选择框、文本域：14～18px。
- [ ] 图标按钮：14～18px；圆形按钮使用50%。
- [ ] 标签、状态、普通按钮：胶囊或12～16px，不允许默认方形按钮。
- [ ] 图片必须继承所属卡片内圆角，外层与内层圆角至少相差6px。
- [ ] 表格外壳、分页、代码工具栏、上传区域、下拉菜单和空状态也必须纳入圆角审计。

### 2.4 线条、边界与层次

- [ ] 普通卡片使用`1px`低对比边框，并增加顶部半透明高光内描边。
- [ ] 可交互卡片悬停时边框颜色渐变到该卡片主题色，不突然变粗。
- [ ] 分隔线不再统一使用长直线；允许短线、点线、渐隐线和带小图标的章节分隔。
- [ ] 输入框聚焦使用“白色内环 + 主题色外环”，避免只有硬蓝框。
- [ ] 阴影分为贴纸、普通卡、浮层、拖拽四级，禁止所有卡片使用相同阴影。
- [ ] 为深色代码块单独设计圆角、工具栏、语言标签和复制反馈。

### 2.5 字体与信息层级

- [ ] 正文继续使用清晰的本地系统中文字体栈。
- [ ] 标题通过字重、字号、字距和小装饰建立个性，不引入远程字体。
- [ ] 首页主标题使用`clamp(40px, 5vw, 68px)`，移动端不低于36px。
- [ ] 正文保持16～18px、1.75～1.9行高；中文文章每行约36～44字。
- [ ] 英文眉题只作辅助，不允许成为主要信息来源。
- [ ] 元信息、标签和按钮文字建立固定字号层级，避免同页面忽大忽小。

### 2.6 专属装饰语言

- [ ] 制作一套本地SVG装饰：云朵、星芒、纸飞机、圆点轨迹、胶带、缝线和小花。
- [ ] 装饰SVG只使用当前主题色变量，可随模块换色。
- [ ] 每屏最多出现3组装饰，装饰面积不超过屏幕内容面积的12%。
- [ ] 装饰不得盖住文字、焦点环或点击区域。
- [ ] 低性能与减少动态模式下装饰保持静态或隐藏。

## 3. 动效与物理反馈重构

### 3.1 动效Token

| 类型 | 时间 | 曲线 | 位移/缩放 |
| --- | --- | --- | --- |
| 即时按下 | 80～110ms | `cubic-bezier(.4,0,.2,1)` | `scale(.94～.97)` + 下移1～2px |
| 释放回弹 | 180～260ms | 软弹簧 | 回到1，可轻微越过到1.01 |
| 普通悬停 | 180～240ms | 标准缓动 | 上移2～4px |
| 卡片进入 | 320～460ms | 入场缓动 | 上移10～18px + 淡入 |
| 抽屉进入 | 360～480ms | 可中断软弹簧 | 移动24～48px |
| 弹窗进入 | 220～300ms | 入场缓动 | `.96 → 1` |
| 成功反馈 | 420～600ms | 两段弹性 | 图标轻弹一次 |

### 3.2 按钮反馈

- [ ] 按下不再只有轻微`scale(.97)`；主按钮采用缩放、阴影收缩和高光下沉三种同步反馈。
- [ ] 松开时产生一次短回弹，不连续抖动。
- [ ] 图标按钮按下时图标额外旋转或位移2px，但不能影响按钮布局。
- [ ] 提交按钮提供默认、悬停、按下、加载、成功、错误、禁用七种状态。
- [ ] 加载状态保持按钮宽度，避免文字变化造成跳动。
- [ ] 触屏设备使用`pointerdown/pointerup/pointercancel`获得与鼠标一致的反馈。

### 3.3 卡片反馈

- [ ] 普通内容卡悬停上移3px，并出现主题色边缘高光。
- [ ] 图片卡内部图片缩放不超过1.035，外层保持稳定裁切。
- [ ] 可点击卡按下缩放至`.985`并下移1px，反馈力度明显但不突兀。
- [ ] 非点击卡不显示误导性的悬停浮起。
- [ ] 桌面可选最大1度指针倾斜，离开后可中断回正；低端设备关闭。

### 3.4 滚动进入与章节节奏

- [ ] 使用`IntersectionObserver`触发一次性章节进入动画。
- [ ] 同组卡片错峰间隔35～55ms，总错峰不超过220ms。
- [ ] 已看过的模块在浏览器后退恢复时不重复播放大幅进入动画。
- [ ] 文章正文不逐段花哨进入，保证阅读稳定。
- [ ] `prefers-reduced-motion`和站内“精简动效”必须关闭位移、倾斜、错峰和持续漂浮。

### 3.5 微动效

- [ ] 导航当前项使用柔和滑动底板，而不是直接切背景色。
- [ ] 标签选择时出现短促的颜色填充和勾选反馈。
- [ ] 输入框获得焦点时标签轻微上移、辅助文字淡入。
- [ ] Toast从边缘弹入，关闭时向来源方向退场。
- [ ] 收藏、点赞、复制、上传完成分别提供不同的小图标动画。
- [ ] 图片上传显示真实进度或明确的处理阶段，不只显示一行静态文字。

## 4. 首页丰富化清单

首页目标是让访客在一屏内识别“你是谁、最近在做什么、能看什么”，继续下滑后形成文章—项目—生活—关系—联系的完整叙事。

### 4.1 首屏Hero

- [ ] 改为非对称三层布局：主介绍纸张、头像/插画星球、当前状态浮卡。
- [ ] 增加可配置短标签，例如“Flask开发 / 设计 / 生活记录”。
- [ ] 增加当前时间、地点或自定义状态，默认关闭精确地理信息。
- [ ] 主按钮、次按钮与随机漫游入口形成三级操作。
- [ ] 头像周围使用轻量轨道、星芒和状态点，支持减少动效。
- [ ] 首屏背景加入极淡网格/纸张纹理和局部云霞，不使用大面积纯白。
- [ ] 后台可配置Hero布局、色调、装饰强度、按钮文字与目标链接。

### 4.2 站点速览条

- [ ] 增加文章数、项目数、动态数、相册数等统计胶囊。
- [ ] 数字只在进入视口时进行一次短计数动画；减少动效时直接显示最终值。
- [ ] 每项统计可点击进入对应页面。
- [ ] 后台可选择显示项与排序。

### 4.3 精选内容舞台

- [ ] 单独展示一篇精选文章，使用大图/大标题与阅读时间。
- [ ] 旁边搭配两篇小文章，形成1大2小而非统一三列。
- [ ] 没有封面时生成本地主题插画，但不同文章不再全部使用同一个云图标。
- [ ] 支持后台手动精选和自动回退到最新置顶文章。

### 4.4 项目展柜

- [ ] 使用横向“桌面展柜”布局：封面、项目说明、技术标签、状态和外链。
- [ ] 支持列表/胶片/堆叠三种后台可选布局。
- [ ] 项目卡的颜色与博客卡区分，优先使用紫蓝和薄荷色。
- [ ] 鼠标悬停展示轻微结构分解或细节浮层，触屏点击仍直接进入详情。

### 4.5 生活动态与时间线

- [ ] 动态改为错落便签或纵向小时间线，避免再使用三张相同白卡。
- [ ] 心情、位置、日期使用独立小图标与主题色。
- [ ] 置顶动态使用奶油黄便签与图钉细节。
- [ ] 文本过长时服务端截断，保持首页高度可控。

### 4.6 相册胶片带

- [ ] 首页增加最近照片胶片带或拍立得堆叠。
- [ ] 使用真实缩略图和固定尺寸占位，避免布局偏移。
- [ ] 支持键盘滚动、触屏横向滑动和“进入相册”按钮。
- [ ] 无照片时展示可爱的本地空状态插画，而非空白区域。

### 4.7 关于我拼贴

- [ ] 将单一横卡升级为头像、简介、技能、所在地、社交入口组成的拼贴区。
- [ ] 展示3～5个重点技能，不在首页放完整履历。
- [ ] 加入“现在 / 使用中 / 正在学习”三个可配置短字段。

### 4.8 友链与留言入口

- [ ] 首页增加精选友链“小星球”列表，最多6项。
- [ ] 增加最近公开留言或留言邀请卡，但不公开邮箱等隐私字段。
- [ ] 友链和留言采用粉色/薄荷色，使首页尾部不再回到单调白灰。

### 4.9 页尾收束

- [ ] 使用一张大号柔和彩色CTA卡收束首页，例如“去博客慢慢逛”或“给我留句话”。
- [ ] 页脚补充站点导航、RSS、后台入口、主题/动效设置和更新时间。

## 5. 公共组件全面重做

### 5.1 按钮

- [ ] 规格：大52px、中46px、小38～40px；所有触控区域至少44px。
- [ ] 变体：主蓝、粉色强调、薄荷成功、奶油提示、柔白次级、文字、危险。
- [ ] 支持左/右图标、仅图标、加载、成功、禁用和组合按钮。
- [ ] 主要按钮增加细高光与按下阴影收缩，不使用纯色扁平矩形。

### 5.2 表单

- [ ] 输入框使用柔和内层底、1px边界、16px圆角和明显聚焦环。
- [ ] 标签、必填标记、帮助文字、字数、错误文字位置统一。
- [ ] 错误状态同时使用图标、文字和颜色，不只变红边。
- [ ] Select、文件上传、日期、复选框、开关均自建一致外观，但保留原生可访问行为。
- [ ] 长表单按信息组放入不同色调的子卡片，避免一整页白色输入框。
- [ ] 提交区在长页面可使用底部粘性操作条。

### 5.3 卡片

- [ ] 定义内容卡、媒体卡、便签卡、统计卡、行动卡、浮层卡六类，而非一个`.card`包办全部。
- [ ] 每类卡片规定圆角、边框、阴影、内边距、标题层级和交互状态。
- [ ] 清理只套白框但没有信息分组意义的嵌套卡片。
- [ ] 列表页交替使用封面位置、颜色和尺寸，减少复制粘贴感。

### 5.4 导航、菜单与弹窗

- [ ] 桌面导航支持当前项滑动底板与轻微吸附反馈。
- [ ] 手机抽屉使用完整的状态机：closed、opening、open、closing。
- [ ] 打开时才显示遮罩；抽屉失败时不得留下单独遮罩。
- [ ] 抽屉使用`100dvh`、安全区、内部滚动、顶部固定标题和底部操作。
- [ ] 打开时给背景主内容设置`inert`，关闭后恢复焦点。
- [ ] 弹窗、下拉、抽屉统一层级Token，消除z-index碰撞。

### 5.5 表格、分页和后台列表

- [ ] 表格置于圆角外壳，表头使用淡色带而非裸灰线。
- [ ] 行悬停、选中和批量操作提供明确状态。
- [ ] 移动端不强行压缩宽表；使用卡片化行或安全横向滚动。
- [ ] 分页改为圆形页码、前后按钮与当前页胶囊。

## 6. 阅读体验修复与增强

### 6.1 阅读进度算法

- [ ] 使用文档坐标计算：`articleStart = article.offsetTop`，`articleEnd = start + article.scrollHeight - viewportHeight`。
- [ ] 进度为`(scrollY - start) / (end - start)`并限制到0～1。
- [ ] 使用`ResizeObserver`监听图片加载、字体变化、窗口尺寸变化并重新计算边界。
- [ ] 使用`requestAnimationFrame`节流scroll更新。
- [ ] 短文章无法形成滚动区时，进入正文后直接显示100%，不产生NaN。
- [ ] 支持手机动态地址栏引起的`visualViewport.height`变化。

### 6.2 进度UI

- [ ] 顶部进度条高度桌面4px、移动端3px，使用蓝—粉渐变和轻微高光。
- [ ] 目录卡中增加实际进度槽、百分比文字和预计剩余时间。
- [ ] 进度颜色必须在浅背景上清晰可见。
- [ ] 文章离开视口后进度保持最终值，不跳回0。
- [ ] 减少动态模式仍即时更新，不使用缓动追赶。

### 6.3 目录与正文

- [ ] 目录使用IntersectionObserver高亮当前标题。
- [ ] 点击目录考虑粘性导航高度，标题不被挡住。
- [ ] 正文图片、引用、代码、表格、提示块、列表和分隔线建立统一样式。
- [ ] 代码块增加本地复制按钮、语言标签和复制成功反馈。
